This snippet provides a reusable custom hook to manage form state in a React application. It helps in handling input values and validation seamlessly.

### `useForm.js` - Custom React Form Hook

```javascript
import { useState } from 'react';

const useForm = (initialValues, validate) => {
  const [values, setValues] = useState(initialValues);
  const [errors, setErrors] = useState({});

  const handleChange = (event) => {
    const { name, value } = event.target;
    setValues({
      ...values,
      [name]: value,
    });

    if (validate) {
      const error = validate(name, value);
      setErrors({
        ...errors,
        [name]: error,
      });
    }
  };

  const handleSubmit = (event, callback) => {
    event.preventDefault();
    if (Object.keys(errors).length === 0) {
      callback(values);
    }
  };

  return {
    values,
    errors,
    handleChange,
    handleSubmit,
  };
};

export default useForm;
```

### Usage Example

```javascript
import React from 'react';
import useForm from './useForm';

const validate = (name, value) => {
  if (!value) {
    return `${name} is required`;
  }
  return '';
};

const MyForm = () => {
  const { values, errors, handleChange, handleSubmit } = useForm(
    { username: '', email: '' },
    validate
  );

  const submitForm = (data) => {
    console.log('Form submitted:', data);
  };

  return (
    <form onSubmit={(event) => handleSubmit(event, submitForm)}>
      <div>
        <label>Username:</label>
        <input
          type="text"
          name="username"
          value={values.username}
          onChange={handleChange}
        />
        {errors.username && <p>{errors.username}</p>}
      </div>
      <div>
        <label>Email:</label>
        <input
          type="email"
          name="email"
          value={values.email}
          onChange={handleChange}
        />
        {errors.email && <p>{errors.email}</p>}
      </div>
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;
```

### Explanation
- **Initial Values**: The `useForm` hook takes an initial state for the form fields.
- **Validation**: A validation function can be provided to check the values during input changes.
- **Form Control**: The hook manages the state of inputs and handles form submission logic.
- **Error Handling**: It keeps track of errors and displays them next to the respective fields.

This custom hook makes form management in React straightforward, reusable, and efficient.
