This code snippet showcases a reusable React component that renders a toggle switch. It allows users to switch between two states (on/off) and provides visual feedback.

### `ToggleSwitch.js` - Reusable Toggle Switch Component
```javascript
import React, { useState } from 'react';
import './ToggleSwitch.css'; // Assuming you have CSS for styling

const ToggleSwitch = ({ initialChecked = false, onChange }) => {
  const [checked, setChecked] = useState(initialChecked);

  const handleToggle = () => {
    const newChecked = !checked;
    setChecked(newChecked);
    if (onChange) {
      onChange(newChecked);
    }
  };

  return (
    <div className={`toggle-switch ${checked ? 'checked' : ''}`} onClick={handleToggle}>
      <div className="toggle-circle" />
    </div>
  );
};

export default ToggleSwitch;
```

- **State Management**: The `useState` hook is used to manage the checked state of the toggle switch.
- **Event Handling**: The `handleToggle` function is called when the switch is clicked, updating the state and calling the `onChange` callback if provided.
