This snippet demonstrates how to create a reusable Modal component in React. It allows you to easily manage the visibility of the modal and accept custom content.

### `Modal.js` - Reusable Modal Component

```jsx
import React from 'react';
import './Modal.css'; // Make sure to create a CSS file for styling

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay">
      <div className="modal-content">
        <button className="close-button" onClick={onClose}>×</button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```jsx
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const toggleModal = () => {
    setModalOpen(!isModalOpen);
  };

  return (
    <div>
      <h1>Welcome to My App</h1>
      <button onClick={toggleModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={toggleModal}>
        <h2>This is a Modal!</h2>
        <p>You can put any content here.</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Modal Component**: The `Modal` component takes `isOpen`, `onClose`, and `children` as props.
- **Conditional Rendering**: It only renders the modal if `isOpen` is true, ensuring it won't show when not needed.
- **Custom Content**: You can pass any content as children to the modal, making it highly reusable.
- **Button for Closing**: The modal includes a button to close it, which calls the `onClose` function provided as a prop.

This reusable modal component can be easily integrated into any React application, providing a clean and functional dialog interface.
