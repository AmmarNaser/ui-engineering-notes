This code snippet demonstrates a reusable React component for a simple modal dialog that can be easily integrated into any application.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import './Modal.css'; // Optional: Include your own styling

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay">
      <div className="modal-content">
        <button className="close-button" onClick={onClose}>X</button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const openModal = () => setModalOpen(true);
  const closeModal = () => setModalOpen(false);

  return (
    <div>
      <h1>Welcome to My App</h1>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={closeModal}>
        <h2>Hello, I'm a Modal!</h2>
        <p>This is a simple reusable modal component.</p>
      </Modal>
    </div>
  );
};

export default App;
```

- **Reusable Component**: The `Modal` component can be used multiple times, passing different content as children.
- **Open/Close Logic**: It handles open and close actions using the `isOpen` prop and `onClose` callback.
- **Styling Flexibility**: You can easily style the modal by adding your own CSS in `Modal.css`.
- **Accessibility**: The close button has an accessible affair to let users easily dismiss the modal.
