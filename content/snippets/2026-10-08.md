This code snippet demonstrates a reusable custom hook in React for toggling boolean state values, which can be particularly useful for handling features like modals, dropdowns, or any on/off functionality.

### `useToggle.js` - Custom Hook for Toggling State
```javascript
import { useState } from 'react';

/**
 * useToggle is a custom hook that manages a boolean state value.
 * @param {boolean} initialValue - The initial state value.
 * @returns {[boolean, function]} - The current state value and a toggle function.
 */
const useToggle = (initialValue = false) => {
  const [value, setValue] = useState(initialValue);
  
  const toggle = () => setValue(prevValue => !prevValue);

  return [value, toggle];
};

export default useToggle;
```

### Usage Example
```javascript
import React from 'react';
import useToggle from './useToggle';

const ToggleComponent = () => {
  const [isToggled, toggle] = useToggle();

  return (
    <div>
      <p>The toggle is {isToggled ? 'ON' : 'OFF'}</p>
      <button onClick={toggle}>Toggle</button>
    </div>
  );
};

const App = () => (
  <div>
    <h1>Toggle Example</h1>
    <ToggleComponent />
  </div>
);

export default App;
```

- **Custom Hook**: `useToggle` encapsulates the logic for managing a boolean state, providing a concise and reusable way to manage toggling.
- **State Management**: It uses React's `useState` to hold the current value and provides a method to toggle this value, streamlining the process of state management in components.
- **Initial Value**: The hook accepts an initial boolean value, allowing for flexibility in its usage based on different component needs.
