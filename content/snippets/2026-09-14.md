This snippet demonstrates how to create a reusable custom button component in React that can be easily styled and configured for various usage scenarios.

### `CustomButton.js` - Reusable Custom Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './CustomButton.css'; // Assuming you have some basic styles here

const CustomButton = ({ onClick, label, primary, disabled }) => {
    const buttonClass = primary ? 'custom-button primary' : 'custom-button';

    return (
        <button
            className={buttonClass}
            onClick={onClick}
            disabled={disabled}
        >
            {label}
        </button>
    );
};

CustomButton.propTypes = {
    onClick: PropTypes.func.isRequired,
    label: PropTypes.string.isRequired,
    primary: PropTypes.bool,
    disabled: PropTypes.bool,
};

CustomButton.defaultProps = {
    primary: false,
    disabled: false,
};

export default CustomButton;
```

ReactDOM.render(<App />, document.getElementById('root'));
