### `CustomButton.js` - Reusable Custom Button Component

```jsx
import React from 'react';
import PropTypes from 'prop-types';

const CustomButton = ({ label, onClick, style, disabled }) => {
  return (
    <button
      onClick={onClick}
      style={{ padding: '10px 15px', borderRadius: '5px', ...style }}
      disabled={disabled}
    >
      {label}
    </button>
  );
};

CustomButton.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  style: PropTypes.object,
  disabled: PropTypes.bool,
};

CustomButton.defaultProps = {
  style: {},
  disabled: false,
};

export default CustomButton;
```

### Usage Example

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
  const handleClick = () => {
    alert('Button Clicked!');
  };

  return (
    <div>
      <h1>Custom Button Demo</h1>
      <CustomButton
        label="Click Me"
        onClick={handleClick}
        style={{ backgroundColor: 'blue', color: 'white' }}
      />
      <CustomButton
        label="Disabled Button"
        onClick={() => {}}
        disabled={true}
        style={{ backgroundColor: 'gray', color: 'white' }}
      />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

- **Customizable Styles**: You can pass a `style` prop to customize the button's appearance, making it flexible for different use cases.
- **Disabled State**: The `disabled` prop prevents the button from being clicked, enhancing user experience by disabling actions when necessary.
- **Prop Types Validation**: By using PropTypes, the component checks the types of props passed to it, ensuring that the correct values are used.
