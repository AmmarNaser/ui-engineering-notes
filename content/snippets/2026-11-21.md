This code snippet demonstrates how to create a reusable modal component in React that can display dynamic content. It includes functionality for opening and closing the modal.

### `Modal.js` - Reusable Modal Component

```jsx
import React, { useState } from 'react';
import './Modal.css'; // Optional CSS for modal styling

const Modal = ({ isOpen, onClose, children }) => {
    if (!isOpen) return null;

    return (
        <div className="modal-overlay">
            <div className="modal-content">
                <button className="close-btn" onClick={onClose}>
                    &times;
                </button>
                {children}
            </div>
        </div>
    );
};

export const App = () => {
    const [isModalOpen, setModalOpen] = useState(false);

    const openModal = () => setModalOpen(true);
    const closeModal = () => setModalOpen(false);

    return (
        <div>
            <h1>Welcome to My App</h1>
            <button onClick={openModal}>Open Modal</button>
            <Modal isOpen={isModalOpen} onClose={closeModal}>
                <h2>This is a Modal</h2>
                <p>You can put any content in here!</p>
            </Modal>
        </div>
    );
};
```

### Usage Example

```jsx
import React from 'react';
```

### Explanation
- **Reusable Component**: The `Modal` component can be reused in different parts of your application with any content passed as children.
- **Dynamic Open/Close**: The modal can be easily toggled open and closed using state management in the parent component.
- **CSS Support**: The component is designed to accept a separate CSS file for styling, promoting a clean separation of concerns.
- **No DOM Manipulation**: The modal utilizes standard React rendering, ensuring performance and maintainability.
