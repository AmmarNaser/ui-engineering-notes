This snippet demonstrates a reusable React component for a customizable button. The button accepts props to manage click events and styles, making it versatile for various use cases.

### `CustomButton.js` - Reusable Custom Button Component
```javascript
import React from 'react';

const CustomButton = ({ onClick, label, style, disabled = false }) => {
  return (
    <button
      onClick={onClick}
      style={{ padding: '10px 20px', ...style }}
      disabled={disabled}
    >
      {label}
    </button>
  );
};

export default CustomButton;
```

### Usage Example
```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>My App</h1>
      <CustomButton
        onClick={handleClick}
        label="Click Me!"
        style={{ backgroundColor: 'blue', color: 'white' }}
      />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Customizable Styles**: The button accepts a `style` prop, allowing users to easily customize its appearance.
- **Disabled State**: The button can be disabled by passing a `disabled` prop, preventing user interaction when needed.
- **Event Handling**: The `onClick` prop enables a custom function to handle click events, providing flexibility for implementing different behaviors.
