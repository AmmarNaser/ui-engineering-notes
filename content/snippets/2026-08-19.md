This snippet demonstrates a simple reusable modal component built with React. It can be used to display any content in a flexible and user-friendly way.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import './Modal.css'; // Assuming you have some basic styles

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={(e) => e.stopPropagation()}>
        <button className="close-button" onClick={onClose}>×</button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isOpen, setIsOpen] = useState(false);

  const openModal = () => setIsOpen(true);
  const closeModal = () => setIsOpen(false);

  return (
    <div>
      <h1>Welcome to My App</h1>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isOpen} onClose={closeModal}>
        <h2>Modal Title</h2>
        <p>This is the modal content!</p>
        <button onClick={closeModal}>Close</button>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Modal Component**: This component takes in `isOpen`, `onClose`, and `children` as props to control its visibility and content.
- **Overlay Click Handling**: Clicking outside the modal content area will close the modal, enhancing user experience.
- **Reusable**: The modal can be reused anywhere in your application, just by passing different children as content.

This modal component provides a scalable solution for incorporating pop-up dialogs throughout your application.
