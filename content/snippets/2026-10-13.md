### `useFetch.js` - Custom Hook for Fetching Data
```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example
```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
  const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/posts');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <ul>
      {data.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
};

export default App;
```

### Explanation
- **Data Fetching**: The custom hook `useFetch` abstracts the data fetching logic and returns response data along with loading and error states.
- **Loading State**: The hook manages a `loading` state to indicate when data is being fetched, providing a user-friendly loading message while fetching.
- **Error Handling**: If the fetch fails, the hook captures the error and makes it available for displaying in the component.
- **Reusability**: This hook can be reused in different components simply by providing different URLs, making it versatile for any API data retrieval.
