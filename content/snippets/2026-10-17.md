This snippet demonstrates a reusable React component that fetches and displays user data from an API. The component is designed to handle loading states and errors gracefully.

### `UserList.js` - Fetch and Display User Data
```jsx
import React, { useEffect, useState } from 'react';

const UserList = () => {
    const [users, setUsers] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchUsers = async () => {
            try {
                const response = await fetch('https://jsonplaceholder.typicode.com/users');
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const data = await response.json();
                setUsers(data);
            } catch (error) {
                setError(error.message);
            } finally {
                setLoading(false);
            }
        };

        fetchUsers();
    }, []);

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error}</p>;

    return (
        <ul>
            {users.map(user => (
                <li key={user.id}>{user.name} - {user.email}</li>
            ))}
        </ul>
    );
};

export default UserList;
```

### Explanation
- **Fetching Data**: The component uses `fetch` to retrieve user data from a public API, specifically `jsonplaceholder.typicode.com`, simulating an actual users API.
- **State Management**: It manages three states: `users` for the fetched data, `loading` for the loading state, and `error` for any potential errors during the fetch.
- **Conditional Rendering**: Displays loading text when data is being fetched, an error message if an error occurs, and the user list once the data has been successfully loaded.
