This snippet demonstrates how to create a simple and reusable modal component in React, which can be easily incorporated into your applications for displaying alerts or custom content.

### `Modal.js` - Reusable Modal Component

```jsx
import React from 'react';
import './Modal.css'; // Import CSS for styling

const Modal = ({ isOpen, onClose, title, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={e => e.stopPropagation()}>
        <h2>{title}</h2>
        <button className="close-button" onClick={onClose}>Close</button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```jsx
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const toggleModal = () => {
    setModalOpen(!isModalOpen);
  };

  return (
    <div>
      <h1>My Application</h1>
      <button onClick={toggleModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={toggleModal} title="My Modal">
        <p>This is the content of the modal.</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be easily reused throughout your application, just by passing different props.
- **Controlled Visibility**: The `isOpen` prop controls whether the modal is displayed, allowing for clean, state-driven UI management.
- **Event Handling**: The modal correctly handles events to close itself when clicking outside the content area, enhancing user experience.
- **Customizable Content**: The `children` prop allows you to pass any content to be displayed inside the modal.

This modal component provides a straightforward way to manage modal dialogs in your React applications, ensuring ease of use and flexibility.
