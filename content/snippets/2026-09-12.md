### `DataFetcher.js` - Fetch Data with Loading State

```javascript
import React, { useState, useEffect } from 'react';

const DataFetcher = ({ url }) => {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err.message);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error}</div>;

    return (
        <div>
            <h2>Data:</h2>
            <pre>{JSON.stringify(data, null, 2)}</pre>
        </div>
    );
};

export default DataFetcher;
```

- **Data Fetching**: The component fetches data from the provided URL when it mounts using the `useEffect` hook.
- **Loading State**: A loading message is displayed while the data is being fetched, providing feedback to the user.
- **Error Handling**: Any errors encountered during fetching are caught and displayed, ensuring a smooth user experience.
- **Reusable Component**: The `DataFetcher` component accepts a `url` prop, making it reusable for different endpoints.
