This snippet demonstrates a reusable React component that toggles a piece of text between being visible and hidden. It is a practical UI element for situations where space conservation is necessary.

### `ToggleText.js` - Text Toggle Component

```javascript
import React, { useState } from 'react';

const ToggleText = ({ text }) => {
    const [isVisible, setIsVisible] = useState(false);

    const toggleVisibility = () => {
        setIsVisible(prevState => !prevState);
    };

    return (
        <div>
            <button onClick={toggleVisibility}>
                {isVisible ? 'Hide' : 'Show'} Text
            </button>
            {isVisible && <p>{text}</p>}
        </div>
    );
};

export default ToggleText;
```
