This snippet demonstrates how to create a reusable modal component in React, allowing for easy integration into different parts of an application.

### `Modal.js` - Reusable Modal Component

```javascript
import React, { useEffect } from 'react';
import './Modal.css'; // Assuming you have some basic styles for the modal

const Modal = ({ isOpen, onClose, children }) => {
    useEffect(() => {
        if (isOpen) {
            document.body.style.overflow = 'hidden'; // Prevent background scrolling
        } else {
            document.body.style.overflow = 'unset'; // Restore scrolling
        }
    }, [isOpen]);

    if (!isOpen) return null;

    return (
        <div className="modal-overlay" onClick={onClose}>
            <div className="modal-content" onClick={(e) => e.stopPropagation()}>
                <button className="modal-close" onClick={onClose}>X</button>
                {children}
            </div>
        </div>
    );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
    const [isModalOpen, setModalOpen] = useState(false);

    const toggleModal = () => {
        setModalOpen(!isModalOpen);
    };

    return (
        <div>
            <h1>Welcome to the Modal Example</h1>
            <button onClick={toggleModal}>Open Modal</button>
            <Modal isOpen={isModalOpen} onClose={toggleModal}>
                <h2>This is a Modal!</h2>
                <p>You can put any content here.</p>
            </Modal>
        </div>
    );
};

export default App;
```

### Explanation
- **Reusable Component**: The Modal component can be reused across different parts of the application, making it flexible for various use cases.
- **Body Overflow Control**: The code alters the body overflow style when the modal is open, preventing background scrolling, which improves user experience.
- **Close on Overlay Click**: Clicking outside the modal content (on the overlay) will trigger the close action, following common UI patterns.
- **Children Prop**: The component accepts children, allowing any valid React elements to be passed into the modal for custom content.

This versatile modal implementation can enhance your app's UI/UX by providing an easy way to display contextual information.
