This snippet demonstrates how to create a reusable button component in React that can handle click events and display different styles based on its props.

### `Button.js` - Reusable Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // Assuming you have some CSS styles for your button

const Button = ({ onClick, children, styleType }) => {
  return (
    <button className={`button ${styleType}`} onClick={onClick}>
      {children}
    </button>
  );
};

Button.propTypes = {
  onClick: PropTypes.func.isRequired,
  children: PropTypes.node.isRequired,
  styleType: PropTypes.oneOf(['primary', 'secondary']),
};

Button.defaultProps = {
  styleType: 'primary',
};

export default Button;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Hello, World!</h1>
      <Button onClick={handleClick} styleType="primary">
        Primary Button
      </Button>
      <Button onClick={handleClick} styleType="secondary">
        Secondary Button
      </Button>
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: The `Button` component can be reused throughout your application with different styles and onClick events.
- **Prop Types Validation**: It uses `PropTypes` to ensure that the correct types are passed to the component, enhancing robustness and reducing bugs.
- **Default Props**: Allows you to specify default styles, improving usability without requiring all props for each button instance.

This component is flexible and can be styled further to fit your application’s design needs.
