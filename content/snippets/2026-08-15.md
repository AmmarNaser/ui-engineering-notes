### `useFetch.js` - Custom Hook for Fetching Data

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default App;
```

### Explanation
- **Custom Hook**: `useFetch` is designed to be reusable across different components, simplifying the process of data fetching.
- **Loading State**: It provides a `loading` state to indicate when the data is being loaded.
- **Error Handling**: The hook captures and returns errors that occur during the fetch, allowing easy error display in the component.
- **Data Management**: The fetched data is stored in the state and returned for use in components.

This custom hook makes API data fetching straightforward, enhancing code modularity and readability.
