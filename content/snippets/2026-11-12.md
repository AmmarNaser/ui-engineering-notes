### `useFormInput.js` - Custom Hook for Form Input Management

```javascript
import { useState } from 'react';

const useFormInput = (initialValue = '') => {
  const [value, setValue] = useState(initialValue);

  const handleChange = (event) => {
    setValue(event.target.value);
  };

  return {
    value,
    onChange: handleChange,
  };
};

export default useFormInput;
```

### Usage Example

```javascript
import React from 'react';
import useFormInput from './useFormInput';

const MyForm = () => {
  const name = useFormInput('');
  const email = useFormInput('');

  const handleSubmit = (event) => {
    event.preventDefault();
    alert(`Name: ${name.value}, Email: ${email.value}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>
          Name:
          <input type="text" {...name} />
        </label>
      </div>
      <div>
        <label>
          Email:
          <input type="email" {...email} />
        </label>
      </div>
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;
```

### Explanation
- **Custom Hook**: The `useFormInput` hook allows for simple and reusable management of form input state.
- **State Management**: It utilizes React's `useState` to keep track of the input value and provides an `onChange` handler to update the state.
- **Destructuring**: The hook returns an object that can be destructured into the input field, simplifying the integration of input management in components.

This custom hook is a great way to streamline form handling in your React applications.
