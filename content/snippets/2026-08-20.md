This snippet demonstrates how to create a reusable modal component in React. The modal can be easily opened and closed, allowing for various content to be displayed dynamically.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import './Modal.css'; // Assuming you have some basic styles for the modal

const Modal = ({ isOpen, onClose, title, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-container" onClick={(e) => e.stopPropagation()}>
        <h2>{title}</h2>
        <button onClick={onClose} className="close-button">Close</button>
        <div className="modal-content">{children}</div>
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const openModal = () => setIsModalOpen(true);
  const closeModal = () => setIsModalOpen(false);

  return (
    <div>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={closeModal} title="My Modal">
        <p>This is a reusable modal component!</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be used multiple times in different parts of your application, with customizable content.
- **Overlay Click Handling**: The modal can be closed by clicking on the overlay, enhancing the user experience.
- **Preventing Event Bubbling**: Clicking inside the modal content does not close the modal, allowing users to interact with the content freely.

This reusable modal component can greatly enhance your application's UI by providing a consistent way to display important information and interact with users.
