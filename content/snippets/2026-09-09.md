This code snippet demonstrates how to create a customizable button component in React that can change its label and color based on props.

### `CustomButton.js` - Customizable Button Component

```jsx
import React from 'react';

const CustomButton = ({ label, color, onClick }) => {
    const buttonStyle = {
        backgroundColor: color,
        color: '#fff',
        border: 'none',
        padding: '10px 20px',
        borderRadius: '5px',
        cursor: 'pointer',
        fontSize: '16px',
    };

    return (
        <button style={buttonStyle} onClick={onClick}>
            {label}
        </button>
    );
};

export default CustomButton;
```

### Usage Example

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
    const handleClick = () => {
        alert('Button clicked!');
    };

    return (
        <div>
            <h1>Welcome to My App</h1>
            <CustomButton label="Click Me!" color="blue" onClick={handleClick} />
            <CustomButton label="Submit" color="green" onClick={handleClick} />
            <CustomButton label="Danger" color="red" onClick={handleClick} />
        </div>
    );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Customizable Label**: The button's label can be dynamically set through the `label` prop.
- **Custom Color**: The `color` prop allows you to change the button’s background color easily.
- **Clickable Event**: The `onClick` prop enables you to pass a function to handle button clicks.

This button component is reusable and can easily fit into any React application, providing both styling and functionality adjustments.
