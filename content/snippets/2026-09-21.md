This code snippet demonstrates how to create a reusable modal component in React, allowing you to easily display content in a popup format throughout your application.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Modal.css'; // Ensure to create a CSS file for styling

const Modal = ({ isOpen, onClose, title, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay">
      <div className="modal-content">
        <h2>{title}</h2>
        <button onClick={onClose} className="close-button">Close</button>
        <div className="modal-body">{children}</div>
      </div>
    </div>
  );
};

Modal.propTypes = {
  isOpen: PropTypes.bool.isRequired,
  onClose: PropTypes.func.isRequired,
  title: PropTypes.string.isRequired,
  children: PropTypes.node.isRequired,
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isOpen, setIsOpen] = useState(false);

  const openModal = () => setIsOpen(true);
  const closeModal = () => setIsOpen(false);

  return (
    <div>
      <h1>Welcome to the Modal Example</h1>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isOpen} onClose={closeModal} title="My Modal">
        <p>This is a reusable modal component.</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be used anywhere in your application, simply by passing `isOpen`, `onClose`, `title`, and `children` as props.
- **Custom Styles**: You can add your own CSS to `Modal.css` to customize the modal's appearance, ensuring it fits the design of your application.
- **Controlled State**: The modal's open/close state is controlled by parent component state, promoting better state management and integration with other application components.

This implementation offers a flexible solution for displaying modal dialogs in your React applications.
