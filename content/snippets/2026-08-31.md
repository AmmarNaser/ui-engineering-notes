This snippet demonstrates a reusable custom hook in React that manages form input state and validation. You can easily integrate it into your forms to handle input changes and validation rules.

### `useFormInput.js` - Custom Hook for Form Inputs
```javascript
import { useState } from 'react';

const useFormInput = (initialValue, validate) => {
  const [value, setValue] = useState(initialValue);
  const [isTouched, setIsTouched] = useState(false);

  const hasError = isTouched && validate && !validate(value);

  const onChange = (event) => {
    setValue(event.target.value);
  };

  const onBlur = () => {
    setIsTouched(true);
  };

  return {
    value,
    hasError,
    onChange,
    onBlur,
  };
};

export default useFormInput;
```

### Usage Example
```javascript
import React from 'react';
import useFormInput from './useFormInput';

const MyForm = () => {
  const validateEmail = (value) => /\S+@\S+\.\S+/.test(value);

  const emailInput = useFormInput('', validateEmail);

  const handleSubmit = (event) => {
    event.preventDefault();
    if (!emailInput.hasError) {
      console.log('Submitted:', emailInput.value);
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Email:</label>
        <input 
          type="email" 
          value={emailInput.value} 
          onChange={emailInput.onChange} 
          onBlur={emailInput.onBlur} 
        />
        {emailInput.hasError && <p style={{ color: 'red' }}>Invalid email address</p>}
      </div>
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;
```

### Explanation
- **State Management**: The hook maintains its own state for the input value and whether the input has been touched.
- **Validation Logic**: A validation function can be passed as an argument, allowing for custom validation rules based on the input value.
- **Error Handling**: Provides a simple way to check for input errors after the input has been blurred, enabling you to display feedback on invalid inputs.

This hook can be reused across multiple forms and inputs, making it a valuable addition to your React applications.
