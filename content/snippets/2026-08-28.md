This snippet demonstrates a reusable custom hook in React for handling form input values and managing form submission.

### `useForm.js` - Custom Hook for Managing Form Inputs

```javascript
import { useState } from 'react';

const useForm = (initialValues, onSubmit) => {
    const [values, setValues] = useState(initialValues);

    const handleChange = (event) => {
        const { name, value } = event.target;
        setValues({
            ...values,
            [name]: value,
        });
    };

    const handleSubmit = (event) => {
        event.preventDefault();
        onSubmit(values);
    };

    return {
        values,
        handleChange,
        handleSubmit,
    };
};

export default useForm;
```

### Usage Example

```javascript
import React from 'react';
import useForm from './useForm';

const MyForm = () => {
    const initialValues = { name: '', email: '' };

    const handleSubmit = (formData) => {
        console.log('Form submitted:', formData);
    };

    const { values, handleChange, handleSubmit: formSubmit } = useForm(initialValues, handleSubmit);

    return (
        <form onSubmit={formSubmit}>
            <div>
                <label>
                    Name:
                    <input
                        type="text"
                        name="name"
                        value={values.name}
                        onChange={handleChange}
                    />
                </label>
            </div>
            <div>
                <label>
                    Email:
                    <input
                        type="email"
                        name="email"
                        value={values.email}
                        onChange={handleChange}
                    />
                </label>
            </div>
            <button type="submit">Submit</button>
        </form>
    );
};

export default MyForm;
```

### Explanation
- **useForm Hook**: This custom hook abstracts away the state management for form inputs, making it easy to reuse across different forms.
- **Initial Values**: It allows you to set initial form values, which can be customized when the hook is used.
- **Event Handlers**: Includes built-in change and submit event handlers that can be wired up to any form.
- **Flexible Submission**: The `onSubmit` callback allows you to define what happens when the form is submitted, providing flexibility for various use cases.

This hook can simplify form management in your React applications, making it easier to handle input states and submissions.
