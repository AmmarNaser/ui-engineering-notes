This snippet demonstrates how to create a reusable modal component in React, complete with customizable content and basic styling.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import './Modal.css';

const Modal = ({ isOpen, onClose, children }) => {
    if (!isOpen) return null;

    return (
        <div className="modal-overlay">
            <div className="modal-content">
                <button className="modal-close" onClick={onClose}>
                    &times;
                </button>
                {children}
            </div>
        </div>
    );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
    const [isModalOpen, setIsModalOpen] = useState(false);

    const openModal = () => setIsModalOpen(true);
    const closeModal = () => setIsModalOpen(false);

    return (
        <div>
            <button onClick={openModal}>Open Modal</button>
            <Modal isOpen={isModalOpen} onClose={closeModal}>
                <h2>Modal Title</h2>
                <p>This is the modal content!</p>
            </Modal>
        </div>
    );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be reused throughout your application with different content by passing `children` as props.
- **Conditional Rendering**: The modal only renders when the `isOpen` prop is `true`, improving performance by not rendering hidden elements.
- **Close Functionality**: The modal includes a close button that triggers the `onClose` function, allowing users to dismiss the modal easily.

This reusable modal component can significantly enhance user experience across your application.
