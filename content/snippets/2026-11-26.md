This snippet demonstrates how to create a reusable button component in React that can be customized with different styles and onClick behavior.

### `Button.js` - Reusable Button Component

```jsx
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // Assuming you have some styles in Button.css

const Button = ({ onClick, label, styleType }) => {
  return (
    <button className={`btn btn-${styleType}`} onClick={onClick}>
      {label}
    </button>
  );
};

Button.propTypes = {
  onClick: PropTypes.func.isRequired,
  label: PropTypes.string.isRequired,
  styleType: PropTypes.string,
};

Button.defaultProps = {
  styleType: 'primary',
};

export default Button;
```

### Usage Example

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>My App</h1>
      <Button onClick={handleClick} label="Click Me" styleType="secondary" />
      <Button onClick={handleClick} label="Submit" styleType="primary" />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: The `Button` component can be reused throughout your application, allowing for consistent styling and behavior.
- **Customizable Props**: Users can specify the button's `label`, click handler (`onClick`), and styling (`styleType`), making it versatile for different scenarios.
- **Default Props**: If no `styleType` is provided, it defaults to 'primary', ensuring there's always a fallback style.

This flexible button component is suitable for a wide range of applications and can be easily styled with external CSS.
