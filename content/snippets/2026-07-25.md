This snippet demonstrates a simple custom React hook for fetching data from an API, helping to manage loading states and errors while making the code cleaner and more reusable.

### `useFetch.js` - Custom Data Fetching Hook

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const DataFetchingComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <div>
      <h1>Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default DataFetchingComponent;
```

### Explanation
- **Custom Hook**: `useFetch` is a reusable hook that encapsulates the logic for fetching data, handling loading and error states.
- **Automatic Cleanup**: The `useEffect` hook ensures that the fetch operation is triggered when the component mounts, and can react to changes in the `url`.
- **Error Handling**: It catches any errors during the fetch operation and updates the state accordingly, allowing the consumer component to display error messages.

This custom hook can be easily integrated into any component that requires data fetching, making it a versatile tool in your React toolkit.
