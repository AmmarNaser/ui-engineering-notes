This React component demonstrates how to create a reusable button with customizable styles and click handling. It can be easily integrated into a larger application.

### `CustomButton.js` - Reusable Customizable Button Component

```javascript
import React from 'react';

const CustomButton = ({ label, onClick, style }) => {
    return (
        <button onClick={onClick} style={{ padding: '10px 20px', borderRadius: '5px', ...style }}>
            {label}
        </button>
    );
};

export default CustomButton;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
    const handleClick = () => {
        alert('Button clicked!');
    };

    return (
        <div>
            <h1>My App</h1>
            <CustomButton 
                label="Click Me!" 
                onClick={handleClick} 
                style={{ backgroundColor: 'blue', color: 'white' }} 
            />
        </div>
    );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

- **Reusability**: The `CustomButton` component can be reused with different labels, styles, and click handlers throughout your application.
