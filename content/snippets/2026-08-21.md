This code snippet showcases a reusable button component in React that can handle loading states and accepts custom styles. It can be very handy in forms or actions where a user needs feedback during processing.

### `LoadingButton.js` - Reusable Loading Button Component

```javascript
import React from 'react';

const LoadingButton = ({ isLoading, onClick, children, style }) => {
  return (
    <button 
      onClick={onClick} 
      style={{ 
        cursor: isLoading ? 'not-allowed' : 'pointer', 
        opacity: isLoading ? 0.6 : 1, 
        ...style 
      }} 
      disabled={isLoading}
    >
      {isLoading ? 'Loading...' : children}
    </button>
  );
};

export default LoadingButton;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import LoadingButton from './LoadingButton';

const App = () => {
  const [loading, setLoading] = useState(false);

  const handleClick = () => {
    setLoading(true);
    setTimeout(() => {
      setLoading(false);
      alert('Action completed!');
    }, 2000); // Simulate a network request
  };

  return (
    <div>
      <h1>Loading Button Example</h1>
      <LoadingButton isLoading={loading} onClick={handleClick} style={{ backgroundColor: 'blue', color: 'white' }}>
        Click Me
      </LoadingButton>
    </div>
  );
};

export default App;
```

### Explanation
- **Loading State**: The button visually indicates when an action is processing, enhancing the user experience.
- **Custom Styles**: It integrates custom styles through props, allowing flexibility in design and appearance.
- **Disabled State**: Automatically disables the button while loading, preventing duplicate actions that could lead to errors.
