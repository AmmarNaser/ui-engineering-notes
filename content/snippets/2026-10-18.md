This code snippet demonstrates a reusable button component in React that can be styled with custom colors and sizes, making it versatile for various use cases in your application.

### `Button.js` - Reusable Styled Button Component

```jsx
import React from 'react';
import PropTypes from 'prop-types';

const Button = ({ label, onClick, color = 'blue', size = 'medium' }) => {
  const styles = {
    backgroundColor: color,
    padding: size === 'large' ? '12px 24px' : size === 'small' ? '6px 12px' : '8px 16px',
    border: 'none',
    borderRadius: '4px',
    color: 'white',
    cursor: 'pointer',
  };

  return (
    <button style={styles} onClick={onClick}>
      {label}
    </button>
  );
};

Button.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  color: PropTypes.string,
  size: PropTypes.oneOf(['small', 'medium', 'large']),
};

export default Button;
```

### Usage Example

```jsx

const App = () => {
  const handleClick = () => {

  };

  return (
    <div>
      <h1>Button Component Example</h1>

    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Customizable Colors**: The button’s background color can be easily changed by passing a `color` prop. It defaults to blue.
- **Responsive Sizes**: You can adjust the button size using the `size` prop, which accepts 'small', 'medium', or 'large' values.
- **Event Handling**: The `onClick` prop allows the parent component to define custom behavior when the button is clicked.
- **Type Checking**: PropTypes ensure that the component receives correct data types for its props, enhancing robustness.
