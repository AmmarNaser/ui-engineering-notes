### `useForm.js` - Custom Hook for Form Management

```javascript
import { useState } from 'react';

const useForm = (initialState, validate) => {
    const [values, setValues] = useState(initialState);
    const [errors, setErrors] = useState({});

    const handleChange = (event) => {
        const { name, value } = event.target;
        setValues({
            ...values,
            [name]: value,
        });
        if (validate) {
            setErrors(validate(values));
        }
    };

    const handleSubmit = (event) => {
        event.preventDefault();
        if (Object.keys(errors).length === 0) {
            // Submit form logic here
        }
    };

    return {
        values,
        errors,
        handleChange,
        handleSubmit,
    };
};

export default useForm;
```

### Usage Example

```javascript
import React from 'react';
import useForm from './useForm';

const validate = (values) => {
    let errors = {};
    if (!values.email) {
        errors.email = "Email is required";
    } else if (!/\S+@\S+\.\S+/.test(values.email)) {
        errors.email = "Email is invalid";
    }
    return errors;
};

const MyForm = () => {
    const { values, errors, handleChange, handleSubmit } = useForm({ email: '' }, validate);

    return (
        <form onSubmit={handleSubmit}>
            <div>
                <label>Email:</label>
                <input 
                    type="email" 
                    name="email" 
                    value={values.email} 
                    onChange={handleChange} 
                />
                {errors.email && <p>{errors.email}</p>}
            </div>
            <button type="submit">Submit</button>
        </form>
    );
};

export default MyForm;
```

- **State Management**: The `useForm` hook manages the state of form values and errors using `useState`.
- **Validation Logic**: It accounts for validation logic by calling a `validate` function, which can be customized and passed as an argument.
- **Reusable Hook**: The hook can be reused across multiple forms with different initial states and validation requirements.
- **Event Handlers**: It provides `handleChange` and `handleSubmit` methods to manage input changes and form submissions effectively.

This custom hook simplifies form handling in React, making it easy to maintain and validate forms across your application.
