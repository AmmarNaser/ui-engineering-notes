This snippet creates a reusable button component in React that supports loading states and customizable styles.

### `Button.js` - Reusable Button Component with Loading State

```jsx
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // optional stylesheet for additional styling

const Button = ({ onClick, isLoading, children, style }) => {
    return (
        <button 
            className="custom-button" 
            onClick={onClick} 
            disabled={isLoading} 
            style={style}
        >
            {isLoading ? (
                <span className="loader"></span>
            ) : (
                children
            )}
        </button>
    );
};

Button.propTypes = {
    onClick: PropTypes.func.isRequired,
    isLoading: PropTypes.bool,
    children: PropTypes.node.isRequired,
    style: PropTypes.object,
};

Button.defaultProps = {
    isLoading: false,
    style: {},
};

export default Button;
```

### Usage Example

```jsx
import React, { useState } from 'react';
import Button from './Button';

const App = () => {
    const [loading, setLoading] = useState(false);

    const handleClick = () => {
        setLoading(true);
        setTimeout(() => setLoading(false), 2000); // simulating an asynchronous action
    };

    return (
        <div>
            <h1>Reusable Button Example</h1>
            <Button onClick={handleClick} isLoading={loading}>
                Click Me!
            </Button>
        </div>
    );
};

export default App;
```

### Explanation
- **Customizable Styles**: The button can accept a `style` prop to apply any custom styles.
- **Loading State**: The button displays a loading indicator (spinner) when the `isLoading` prop is true, providing visual feedback to the user.
- **Prop Validation**: It uses PropTypes to ensure that the `onClick` function is required and that `isLoading` is a boolean.
