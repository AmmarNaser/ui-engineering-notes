This code snippet demonstrates how to create a reusable button component in React, complete with customizable text and styling props.

### `CustomButton.js` - Reusable Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';

const CustomButton = ({ label, onClick, style }) => {
  return (
    <button onClick={onClick} style={{ padding: '10px 20px', ...style }}>
      {label}
    </button>
  );
};

CustomButton.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  style: PropTypes.object,
};

CustomButton.defaultProps = {
  style: {},
};

export default CustomButton;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Custom Button Example</h1>
      <CustomButton 
        label="Click Me" 
        onClick={handleClick} 
        style={{ backgroundColor: 'blue', color: 'white' }} 
      />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: The `CustomButton` is a functional component that accepts props, making it easy to use multiple times with different configurations.

- **Default Props**: The component provides default styling if no custom styles are passed, allowing for flexibility while ensuring a basic look.
