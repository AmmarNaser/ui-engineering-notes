This code snippet demonstrates how to create a reusable button component in React that can be styled based on its type (primary, secondary, etc.) and also handle click events.

### `Button.js` - Reusable Button Component

```jsx
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // Assuming you have some basic CSS for buttons there.

const Button = ({ type, onClick, children }) => {
  return (
    <button className={`btn btn-${type}`} onClick={onClick}>
      {children}
    </button>
  );
};

Button.propTypes = {
  type: PropTypes.oneOf(['primary', 'secondary', 'danger']),
  onClick: PropTypes.func.isRequired,
  children: PropTypes.node.isRequired,
};

Button.defaultProps = {
  type: 'primary',
};

export default Button;
```

### Usage Example

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Button Component Example</h1>
      <Button type="primary" onClick={handleClick}>Primary Button</Button>
      <Button type="secondary" onClick={handleClick}>Secondary Button</Button>
      <Button type="danger" onClick={handleClick}>Danger Button</Button>
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: This button component can be reused across your application, allowing for consistent styling and functionality.
- **Type Prop**: The `type` prop accepts different values (primary, secondary, danger) to easily change the button's appearance.
- **Click Handling**: The component takes an `onClick` function that allows parent components to define what happens when the button is clicked.
- **CSS Integration**: The component expects an external CSS file (Button.css) to define the styles for different button types.

This button component is great for maintaining a consistent look and feel throughout your application.
