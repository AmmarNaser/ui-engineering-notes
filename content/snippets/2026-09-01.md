This snippet demonstrates a reusable React component for a modal dialog that can display any content passed to it as a prop. The modal can be opened and closed, providing a simple way to manage visibility.

### `Modal.js` - Reusable Modal Component

```javascript
import React, { useState } from 'react';
import './Modal.css'; // Assume CSS for modal styling is defined in this file.

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay">
      <div className="modal-content">
        <button className="modal-close" onClick={onClose}>
          &times;
        </button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const openModal = () => setModalOpen(true);
  const closeModal = () => setModalOpen(false);

  return (
    <div>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={closeModal}>
        <h1>Hello, World!</h1>
        <p>This is a simple modal dialog.</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be used throughout the application wherever a modal is needed by simply passing different content as children.
- **Visibility Control**: The `isOpen` prop controls the visibility of the modal, allowing it to be shown or hidden based on state.
- **Close Functionality**: The `onClose` prop is a callback function that is called to handle when the modal is closed, ensuring the parent component can manage the modal's state.

This modal component can be easily integrated into various parts of your application, helping to create a consistent user experience.
