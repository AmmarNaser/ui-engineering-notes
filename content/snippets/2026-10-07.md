This snippet demonstrates a reusable custom React hook for fetching data from an API. The hook manages loading and error states, making it easy to integrate into your components.

### `useFetch.js` - Custom Data Fetching Hook

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error(`Error: ${response.statusText}`);
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
  const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/posts');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div>
      <h1>Posts</h1>
      <ul>
        {data.map(post => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
};

export default App;
```

### Explanation
- **Data Fetching**: The hook fetches data from the provided URL, handling the asynchronous operation with `useEffect`.
- **Loading State**: It maintains a loading state that indicates whether the data is still being fetched.
- **Error Handling**: If an error occurs during the fetch process, it is captured and made available for display.
- **Reusability**: This hook can be used in any component that requires API data fetching, simply by passing a different URL.

This custom hook streamlines the process of data fetching across your application, reducing boilerplate code.
