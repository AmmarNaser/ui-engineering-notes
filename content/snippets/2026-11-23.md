This code snippet demonstrates how to create a simple reusable button component in React that can handle different styles and click events.

### `Button.js` - Reusable Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // Optional styling

const Button = ({ label, onClick, styleType }) => {
  return (
    <button className={`btn ${styleType}`} onClick={onClick}>
      {label}
    </button>
  );
};

Button.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  styleType: PropTypes.oneOf(['primary', 'secondary']).isRequired,
};

export default Button;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Button Component Example</h1>
      <Button label="Click Me" onClick={handleClick} styleType="primary" />
      <Button label="Submit" onClick={handleClick} styleType="secondary" />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Props Usage**: The component accepts three props: `label`, `onClick`, and `styleType` to ensure flexibility.
- **Styling Options**: It supports two styling types, `primary` and `secondary`, allowing easy customization through CSS.
- **Validation**: PropTypes are used to enforce type checking for the props, enhancing reliability.

This reusable button component makes it easy to create clickable buttons with different styles in your React application.
