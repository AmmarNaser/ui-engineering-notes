This snippet demonstrates how to create a reusable custom button component in React, allowing for the customization of styles and functionality.

### `CustomButton.js` - Reusable Custom Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';

const CustomButton = ({ label, onClick, style, disabled }) => (
  <button 
    onClick={onClick} 
    style={style} 
    disabled={disabled} 
    className="custom-button"
  >
    {label}
  </button>
);

CustomButton.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  style: PropTypes.object,
  disabled: PropTypes.bool,
};

CustomButton.defaultProps = {
  style: {},
  disabled: false,
};

export default CustomButton;
```
