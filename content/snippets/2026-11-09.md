This code snippet demonstrates a reusable custom button component in React with different styles based on props, allowing for a versatile design in your applications.

### `CustomButton.js` - Reusable Custom Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './CustomButton.css'; // Optional: Include custom styles

const CustomButton = ({ label, onClick, variant = 'default' }) => {
  return (
    <button className={`custom-button ${variant}`} onClick={onClick}>
      {label}
    </button>
  );
};

CustomButton.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  variant: PropTypes.oneOf(['default', 'primary', 'secondary']),
};

export default CustomButton;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Custom Button Example</h1>
      <CustomButton label="Default Button" onClick={handleClick} />
      <CustomButton label="Primary Button" onClick={handleClick} variant="primary" />
      <CustomButton label="Secondary Button" onClick={handleClick} variant="secondary" />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

- **Reusable Component**: The `CustomButton` can be used with different labels and click handlers without code duplication.
