This snippet demonstrates a reusable custom React hook that fetches data from an API. It handles loading and error states, making it ideal for integrating API calls in various components.

### `useFetch.js` - Custom Data Fetching Hook

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error(`Error: ${response.statusText}`);
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const DataDisplay = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <h1>Data fetched from API:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default DataDisplay;
```

### Explanation
- **Custom Hook**: `useFetch` abstracts away the logic of fetching data, allowing for cleaner component code.
- **Loading State**: Tracks the loading status to provide user feedback while the data is being fetched.
- **Error Handling**: Captures any errors during the fetch process and provides an appropriate message.

This custom hook can be reused across different components to simplify data fetching logic consistently.
