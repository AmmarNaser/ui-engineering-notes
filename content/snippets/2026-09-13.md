This code snippet demonstrates how to create a reusable modal component in React. It allows users to easily display content in a modal format, enhancing the user interface experience.

### `Modal.js` - Reusable Modal Component

```javascript
import React, { useEffect } from 'react';
import './Modal.css'; // Assume you have some CSS for styling

const Modal = ({ isOpen, onClose, children }) => {
  useEffect(() => {
    if (isOpen) {
      document.body.style.overflow = 'hidden';
    } else {
      document.body.style.overflow = 'unset';
    }
  }, [isOpen]);

  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={(e) => e.stopPropagation()}>
        <button className="close-button" onClick={onClose}>
          &times;
        </button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isOpen, setIsOpen] = useState(false);

  const toggleModal = () => setIsOpen(!isOpen);

  return (
    <div>
      <button onClick={toggleModal}>Open Modal</button>
      <Modal isOpen={isOpen} onClose={toggleModal}>
        <h2>Modal Title</h2>
        <p>This is a reusable modal component!</p>
        <button onClick={toggleModal}>Close Modal</button>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusability**: The `Modal` component accepts `isOpen`, `onClose`, and `children` props, allowing it to be reused with different content and control mechanisms.
- **Accessibility**: The modal locks the body scroll when open, improving the user experience by reducing background distractions.
- **Close Functionality**: Users can close the modal by clicking the close button or anywhere outside the modal content, enhancing usability.

This modular approach allows you to easily integrate modals throughout your application.
