This snippet demonstrates how to create a reusable modal component in React, allowing for dynamic content and flexible customization.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Modal.css'; // Make sure to create a CSS file for styling

const Modal = ({ isOpen, onClose, title, children }) => {
    if (!isOpen) return null;

    return (
        <div className="modal-overlay">
            <div className="modal-content">
                <h2>{title}</h2>
                <button className="close-button" onClick={onClose}>Close</button>
                <div className="modal-body">
                    {children}
                </div>
            </div>
        </div>
    );
};

Modal.propTypes = {
    isOpen: PropTypes.bool.isRequired,
    onClose: PropTypes.func.isRequired,
    title: PropTypes.string,
    children: PropTypes.node,
};

Modal.defaultProps = {
    title: 'Modal Title',
    children: null,
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
    const [isModalOpen, setIsModalOpen] = useState(false);

    const toggleModal = () => {
        setIsModalOpen(!isModalOpen);
    };

    return (
        <div>
            <h1>My Application</h1>
            <button onClick={toggleModal}>Open Modal</button>
            <Modal isOpen={isModalOpen} onClose={toggleModal} title="My Modal">
                <p>This is the content of the modal!</p>
            </Modal>
        </div>
    );
};

export default App;
```

### Explanation
- **Reusable Component**: The `Modal` component can be used multiple times by passing different props for title and content.
- **Dynamic Rendering**: The modal is conditionally rendered based on the `isOpen` prop, making it easy to show or hide.
- **Customizable Content**: You can pass any children elements to the modal, allowing for flexible content options.
- **Prop Types**: Uses PropTypes to ensure correct type checking for props.
