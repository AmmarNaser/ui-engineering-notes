This snippet demonstrates how to create a simple reusable modal component in React using hooks. The modal can be opened and closed, making it suitable for various use cases.

### `Modal.js` - Reusable Modal Component

```jsx
import React, { useState } from 'react';
import './Modal.css'; // Import your styles

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay">
      <div className="modal-content">
        <button onClick={onClose} className="close-button">Close</button>
        {children}
      </div>
    </div>
  );
};

export const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const openModal = () => setModalOpen(true);
  const closeModal = () => setModalOpen(false);

  return (
    <div>
      <button onClick={openModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={closeModal}>
        <h2>Hello from Modal!</h2>
        <p>This is a reusable modal component.</p>
      </Modal>
    </div>
  );
};

export default Modal;
```

### Explanation
- **Reusable component**: The modal can be used anywhere in your application by passing props for its state and content.
- **Conditional rendering**: The modal only renders when the `isOpen` prop is `true`, which saves resources and improves performance.
- **Button for closing**: A simple button inside the modal allows users to close it, enhancing user experience.

This modal component can be easily integrated into any application that requires modal functionality.
