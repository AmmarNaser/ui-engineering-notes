This snippet demonstrates how to create a reusable modal component in React, allowing you to display content in an overlay while maintaining the main application context.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Modal.css'; // Assumes there is a CSS file for styling the modal

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={e => e.stopPropagation()}>
        <button className="modal-close" onClick={onClose}>X</button>
        {children}
      </div>
    </div>
  );
};

Modal.propTypes = {
  isOpen: PropTypes.bool.isRequired,
  onClose: PropTypes.func.isRequired,
  children: PropTypes.node.isRequired,
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  const toggleModal = () => {
    setModalOpen(!isModalOpen);
  };

  return (
    <div>
      <button onClick={toggleModal}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={toggleModal}>
        <h2>Hello, I am a Modal!</h2>
        <p>This is a reusable modal component example.</p>
      </Modal>
    </div>
  );
};

export default App;
```

- **Modal Component**: A functional React component that renders an overlay when `isOpen` is true.
- **Prop Validation**: Utilizes PropTypes to ensure that the correct data types are passed as props.
- **Event Prevention**: Contains logic to prevent event propagation so that clicking inside the modal content does not close it unintentionally.
- **Customizable Content**: You can pass any child components to the modal, making it flexible for various use cases.
