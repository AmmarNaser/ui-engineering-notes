This React snippet demonstrates how to create a reusable button component that can be customized with various styles, onClick actions, and labels.

### `CustomButton.js` - Reusable Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './CustomButton.css'; // Include styles for button

const CustomButton = ({ label, onClick, styleType }) => {
    return (
        <button className={`custom-button ${styleType}`} onClick={onClick}>
            {label}
        </button>
    );
};

CustomButton.propTypes = {
    label: PropTypes.string.isRequired,
    onClick: PropTypes.func.isRequired,
    styleType: PropTypes.oneOf(['primary', 'secondary', 'danger']).isRequired,
};

export default CustomButton;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import CustomButton from './CustomButton';
import './styles.css';

const App = () => {
    const handleClick = (type) => {
        alert(`You clicked the ${type} button!`);
    };

    return (
        <div>
            <CustomButton label="Primary Button" onClick={() => handleClick('Primary')} styleType="primary" />
            <CustomButton label="Secondary Button" onClick={() => handleClick('Secondary')} styleType="secondary" />
            <CustomButton label="Danger Button" onClick={() => handleClick('Danger')} styleType="danger" />
        </div>
    );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: The `CustomButton` component can be used throughout the application by passing different props for label, action, and styling.
- **Props Validation**: Utilizes `PropTypes` to enforce expected prop types and enhance reliability.
- **Customizable Styles**: The button's style can be changed easily using different style types, which allows for consistent design across the application.
