This snippet provides a reusable custom hook for fetching data from an API in a React application. It manages loading states and error handling, making it easy to integrate into any component.

### `useFetch.js` - Custom Hook for Fetching Data
```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
};

export default useFetch;
```

### Usage Example
```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
    const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/posts');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error.message}</div>;

    return (
        <div>
            <h1>Posts</h1>
            <ul>
                {data.map(post => (
                    <li key={post.id}>{post.title}</li>
                ))}
            </ul>
        </div>
    );
};

export default App;
```

### Explanation
- **Custom Hook**: The `useFetch` hook abstracts the fetching logic, allowing for easy reuse across components.
- **Loading State**: Manages a loading state to indicate when data is being fetched.
- **Error Handling**: Catches and stores any errors that occur during the fetch process, enabling graceful error management.
- **Dependency Array**: Updates the fetch whenever the URL changes, making it dynamic.

This custom hook simplifies data fetching in your React components, promoting the DRY (Don't Repeat Yourself) principle.
