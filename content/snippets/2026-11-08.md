This snippet demonstrates how to create a reusable button component in React that can handle different styles and actions based on props.

### `Button.js` - Reusable Button Component

```jsx
import React from 'react';
import PropTypes from 'prop-types';

const Button = ({ onClick, label, styleType }) => {
  const buttonStyles = {
    primary: {
      backgroundColor: '#007bff',
      color: '#fff',
    },
    secondary: {
      backgroundColor: '#6c757d',
      color: '#fff',
    },
    danger: {
      backgroundColor: '#dc3545',
      color: '#fff',
    },
  };

  return (
    <button
      onClick={onClick}
      style={{ ...buttonStyles[styleType], padding: '10px 20px', border: 'none', borderRadius: '5px' }}
    >
      {label}
    </button>
  );
};

Button.propTypes = {
  onClick: PropTypes.func.isRequired,
  label: PropTypes.string.isRequired,
  styleType: PropTypes.oneOf(['primary', 'secondary', 'danger']),
};

Button.defaultProps = {
  styleType: 'primary',
};

export default Button;
```

### Usage Example

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <Button onClick={handleClick} label="Primary Button" styleType="primary" />
      <Button onClick={handleClick} label="Secondary Button" styleType="secondary" />
      <Button onClick={handleClick} label="Danger Button" styleType="danger" />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Custom Styles**: The button can accept different styles through the `styleType` prop, allowing for consistent theming across the application.
- **Prop Type Validation**: Utilizing `PropTypes` ensures that the correct data types are passed, providing better maintainability and avoiding potential bugs.
- **Default Props**: The button has a default style type, ensuring that it remains functional and visually appealing even when the `styleType` prop is not specified.

This component can easily be integrated into any React application to provide uniform button functionality and appearance.
