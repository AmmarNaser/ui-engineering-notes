This snippet demonstrates a reusable React hook that manages local storage for storing and retrieving stateful values, making it easy for developers to persist data across sessions.

### `useLocalStorage.js` - Custom Hook for Local Storage Management

```javascript
import { useState } from 'react';

const useLocalStorage = (key, initialValue) => {
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      console.error(error);
      return initialValue;
    }
  });

  const setValue = (value) => {
    try {
      const valueToStore = value instanceof Function ? value(storedValue) : value;
      setStoredValue(valueToStore);
      window.localStorage.setItem(key, JSON.stringify(valueToStore));
    } catch (error) {
      console.error(error);
    }
  };

  return [storedValue, setValue];
};

export default useLocalStorage;
```

### Usage Example

```javascript
import React from 'react';
import useLocalStorage from './useLocalStorage';

const App = () => {
  const [name, setName] = useLocalStorage('name', 'John Doe');

  return (
    <div>
      <h1>Hello, {name}!</h1>
      <input 
        type="text" 
        value={name} 
        onChange={(e) => setName(e.target.value)} 
        placeholder="Enter your name" 
      />
    </div>
  );
};

export default App;
```

### Explanation
- **Persistent State**: The `useLocalStorage` hook allows you to save stateful values that persist even after a page refresh or reopening the browser.
- **Initial Value Handling**: It accepts an initial value that will be used if no value is found in local storage, providing a way to specify default settings.
- **Error Handling**: The hook includes error catching to handle cases where local storage may not be available or other issues occur gracefully.

This custom hook simplifies managing local storage in React applications, promoting cleaner code and enhanced user experience.
