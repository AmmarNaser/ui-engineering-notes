This snippet demonstrates how to create a reusable modal component in React that can be opened and closed with simple props. It's a common UI pattern used in many applications.

### `Modal.js` - Reusable Modal Component

```javascript
import React from 'react';
import './Modal.css'; // Optional CSS

const Modal = ({ isOpen, onClose, children }) => {
  if (!isOpen) return null;

  return (
    <div className="modal-overlay" onClick={onClose}>
      <div className="modal-content" onClick={(e) => e.stopPropagation()}>
        <button className="modal-close" onClick={onClose}>×</button>
        {children}
      </div>
    </div>
  );
};

export default Modal;
```

### Usage Example

```javascript
import React, { useState } from 'react';
import Modal from './Modal';

const App = () => {
  const [isModalOpen, setModalOpen] = useState(false);

  return (
    <div>
      <h1>My App</h1>
      <button onClick={() => setModalOpen(true)}>Open Modal</button>
      <Modal isOpen={isModalOpen} onClose={() => setModalOpen(false)}>
        <h2>Modal Title</h2>
        <p>This is the modal content.</p>
      </Modal>
    </div>
  );
};

export default App;
```

### Explanation
- **Reusable Modal**: The `Modal` component can be used in different parts of your application. You can pass in any content as children.
- **Close Functionality**: The modal can be closed either by clicking the close button or outside the modal area, thanks to event propagation handling.
- **Conditional Rendering**: The modal only renders if the `isOpen` prop is true, preventing unnecessary DOM elements when it’s not needed.

This modal implementation is a great way to keep your UI modular and maintainable.
