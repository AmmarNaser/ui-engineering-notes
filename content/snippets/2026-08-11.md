This snippet demonstrates how to create a reusable button component in React that can be styled and customized through props.

### `Button.js` - Reusable Button Component

```javascript
import React from 'react';
import PropTypes from 'prop-types';
import './Button.css'; // Optional: for custom styling

const Button = ({ label, onClick, styleType }) => {
  return (
    <button className={`button ${styleType}`} onClick={onClick}>
      {label}
    </button>
  );
};

Button.propTypes = {
  label: PropTypes.string.isRequired,
  onClick: PropTypes.func.isRequired,
  styleType: PropTypes.oneOf(['primary', 'secondary']),
};

Button.defaultProps = {
  styleType: 'primary',
};

export default Button;
```

### Usage Example

```javascript
import React from 'react';
import ReactDOM from 'react-dom';
import Button from './Button';

const App = () => {
  const handleClick = () => {
    alert('Button clicked!');
  };

  return (
    <div>
      <h1>Hello, World!</h1>
      <Button label="Click Me" onClick={handleClick} styleType="primary" />
      <Button label="Secondary Button" onClick={handleClick} styleType="secondary" />
    </div>
  );
};

ReactDOM.render(<App />, document.getElementById('root'));
```

### Explanation
- **Reusable Component**: The `Button` component is designed to be easily reused across your application with different labels and actions.
- **Props for Customization**: The component accepts `label`, `onClick`, and `styleType` props, allowing for flexible usage and styling based on requirements.
- **PropTypes for Validation**: Using PropTypes helps in validating the props passed to the component, ensuring they meet expected types and reducing bugs.

This button component can be styled easily via CSS and integrated into various parts of your application.
