### `useFetch.js` - Custom Hook for Data Fetching

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            setLoading(true);
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err.message);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
    const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/posts');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error}</div>;

    return (
        <div>
            <h1>Posts</h1>
            <ul>
                {data.map(post => (
                    <li key={post.id}>{post.title}</li>
                ))}
            </ul>
        </div>
    );
};

export default App;
```

### Explanation
- **Data Fetching**: The `useFetch` hook fetches data from a given URL using the Fetch API.
- **Loading State**: While the data is being fetched, a loading state is managed, allowing for a loading indication to the user.
- **Error Handling**: If the fetch fails, the error state captures and displays the error message.
- **Reusable Hook**: This custom hook can be used across different components, just by providing the desired URL. 

This hook encapsulates the entire fetch logic, making it straightforward and maintainable for any data-fetching requirements in your application.
