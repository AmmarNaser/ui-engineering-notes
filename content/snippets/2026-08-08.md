This snippet demonstrates a reusable custom React hook that fetches data from an API and manages loading and error states, making it easy to integrate API calls into functional components.

### `useFetch.js` - Custom Hook for Data Fetching

```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error(`HTTP error! Status: ${response.status}`);
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Usage Example

```javascript
import React from 'react';
import useFetch from './useFetch';

const App = () => {
  const { data, loading, error } = useFetch('https://jsonplaceholder.typicode.com/posts');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div>
      <h1>Posts</h1>
      <ul>
        {data.map(post => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
};

export default App;
```

### Explanation
- **Data Fetching**: The `useFetch` hook takes a URL as an argument and fetches data from that URL.
- **Loading State**: It manages a loading state to indicate when the data is being fetched.
- **Error Handling**: If an error occurs during the fetch operation, it captures the error message and provides it for display.
- **Reusability**: This hook can be reused across different components with different URLs, making it versatile for various API calls.

This custom hook simplifies the process of fetching data and handling loading and error states, allowing you to focus on building your UI.
