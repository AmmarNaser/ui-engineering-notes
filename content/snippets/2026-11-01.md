### `useForm.js` - Custom Hook for Form Inputs

```javascript
import { useState } from 'react';

/**
 * useForm is a custom React hook for managing form inputs.
 * 
 * @param {Object} initialValues - Initial form field values.
 * @returns {Array} - An array containing form values, a change handler, and a reset function.
 */
export const useForm = (initialValues = {}) => {
  const [values, setValues] = useState(initialValues);

  const handleChange = (e) => {
    const { name, value } = e.target;
    setValues((prevValues) => ({ ...prevValues, [name]: value }));
  };

  const resetForm = () => {
    setValues(initialValues);
  };

  return [values, handleChange, resetForm];
};
```

### Usage Example

```javascript
import React from 'react';
import { useForm } from './useForm';

const MyForm = () => {
  const [formValues, handleInputChange, resetForm] = useForm({ name: '', email: '' });

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log('Form submitted:', formValues);
    resetForm();
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>
          Name:
          <input type="text" name="name" value={formValues.name} onChange={handleInputChange} />
        </label>
      </div>
      <div>
        <label>
          Email:
          <input type="email" name="email" value={formValues.email} onChange={handleInputChange} />
        </label>
      </div>
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;
```

### Explanation
- **Custom Hook**: `useForm` is a custom hook that encapsulates the state and behavior of form inputs.
- **Change Handler**: The `handleChange` function updates the state whenever an input changes, leveraging the `name` attribute to identify each field.
- **Reset Functionality**: The `resetForm` function allows resetting the form to its initial state, making it easy to clear the fields after submission.
- **Initial Values**: You can pass initial values to the hook, making it flexible for different forms.

This hook can greatly simplify form management in React applications and can be used across various forms.
