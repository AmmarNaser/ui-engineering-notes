### React Hook - Understanding useEffect for Side Effects

The `useEffect` hook is a crucial part of React that allows developers to perform side effects in functional components. It can be thought of as the counterpart to lifecycle methods in class components, enabling controlled execution of code after rendering.

### When to Use It
- **Fetching Data**: Use `useEffect` to initiate data fetching from an API when the component mounts.
- **Event Listeners**: Use it to set up event listeners that should be added when a component is rendered and removed when it’s unmounted.

### Example
```jsx
import React, { useState, useEffect } from 'react';

const DataFetcher = () => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch('https://api.example.com/data');
      const result = await response.json();
      setData(result);
      setLoading(false);
    };
    
    fetchData();
  }, []); // Empty dependency array means this runs once on mount

  if (loading) return <p>Loading...</p>;
  return <div>{JSON.stringify(data)}</div>;
};

export default DataFetcher;
```

### Explanation
- **Initialization**: The `useEffect` hook runs after the first render as well as after every update unless you provide a dependency array. 
- **Cleanup**: You can return a cleanup function from `useEffect` to perform actions when the component unmounts or before the effect runs again, such as removing event listeners.

By understanding and utilizing `useEffect`, you can effectively manage side effects in your React applications, making your code cleaner and more efficient.
