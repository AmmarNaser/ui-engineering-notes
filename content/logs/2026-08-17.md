### Custom Hooks - Creating Reusable Logic in React

Custom hooks are JavaScript functions that allow you to extract component logic into reusable functions. By using custom hooks, you can share stateful logic between components without changing the component hierarchy, which enhances code organization and reduces duplication.

### When to Use It
- **Shared Logic**: When multiple components need to use the same stateful logic, such as fetching data or managing form inputs.
- **Complex State Management**: When a component has complex behavior that can be decoupled from the UI, making the code easier to read and maintain.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (error) {
                setError(error);
            } finally {
                setLoading(false);
            }
        };
        fetchData();
    }, [url]);

    return { data, loading, error };
}

export default useFetch;
```

### Explanation
- **Reusability**: Custom hooks allow you to reuse logic across different components, which leads to cleaner and DRYer (Don't Repeat Yourself) code.
- **Encapsulation**: By encapsulating logic in a hook, you separate concerns, keeping your components focused on the UI while the hook manages state and side effects.

In summary, custom hooks are a powerful feature in React that enhance code reusability and organization by separating component logic into reusable functions.
