### State Management - Understanding useState Hook

State management is a crucial concept in React that allows components to manage their own state and re-render when that state changes. The `useState` hook is one of the fundamental hooks that enables function components to hold and manage local state.

### Concept Explanation
The `useState` hook is a built-in React function that lets you add state to functional components. When you call `useState`, it returns an array containing two elements: the current state value and a function that updates that value. This is important for creating interactive components that respond to user input and other events by re-rendering as necessary while maintaining the current state.

### When to Use It
- **Form Inputs**: Use `useState` for managing the value of form inputs in a controlled component.
- **Toggle State**: Utilize `useState` to manage boolean states in components, such as expanding/collapsing sections or modal visibility.

### Example
```jsx
import React, { useState } from 'react';

const ToggleButton = () => {
  const [isToggled, setIsToggled] = useState(false);

  const handleToggle = () => {
    setIsToggled(prevState => !prevState);
  };

  return (
    <div>
      <button onClick={handleToggle}>
        {isToggled ? 'ON' : 'OFF'}
      </button>
    </div>
  );
};

export default ToggleButton;
```

### Explanation
- **State Initialization**: You initialize state with a default value (in this case, `false`) using `useState`.
- **State Update Function**: The second element in the array returned by `useState` is a function (`setIsToggled`) that updates the state. You can use it to toggle the state with a callback that receives the previous state.

This hook allows for creating dynamic, interactive user interfaces in React, making it a vital tool in any React developer's toolbox.
