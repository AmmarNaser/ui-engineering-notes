### Hooks - Managing State with `useState` in React

React Hooks, specifically the `useState` hook, provide a powerful way to manage state in functional components. Unlike class components, functional components can now hold and manipulate state directly, leading to cleaner and more understandable code.

### When to Use It
- **Managing Local State**: Use `useState` when you need to manage local state in a functional component, such as toggling a button or handling form inputs.
- **Dynamic Data**: Utilize `useState` for components that require dynamic data updates based on user interactions or API responses.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <button onClick={() => setCount(count - 1)}>Decrement</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Initialization**: `useState(0)` initializes the state variable `count` with an initial value of `0`.
- **State Update**: The `setCount` function updates the state, triggering a re-render of the component whenever it's called.

By using the `useState` hook, you can easily manage the state of functional components in React, making your code more maintainable and efficient.
