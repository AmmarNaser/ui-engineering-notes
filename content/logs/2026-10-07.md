### Controlled Components - Managing Form Inputs in React

Controlled components are a fundamental concept in React that allows developers to manage form inputs' state through the component's state. This approach ensures that the form input values are derived from and controlled by React, leading to better predictability and easier validation.

### When to Use It
- **Form Handling**: Use controlled components when you want to manage and validate user input seamlessly within a React component.
- **Dynamic Form Elements**: When building forms with dynamic elements that depend on user interactions or previous inputs, controlled components offer the flexibility needed to react to state changes.

### Example
```jsx
import React, { useState } from 'react';

const ControlledForm = () => {
  const [name, setName] = useState('');

  const handleChange = (event) => {
    setName(event.target.value);
  };

  const handleSubmit = (event) => {
    event.preventDefault();
    alert(`A name was submitted: ${name}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Name:
        <input type="text" value={name} onChange={handleChange} />
      </label>
      <button type="submit">Submit</button>
    </form>
  );
};

export default ControlledForm;
```

### Explanation
- **State Management**: Controlled components store input values in React state, making it easy to access and manipulate.
- **Single Source of Truth**: By connecting form inputs to state, you ensure that the displayed values always reflect the latest state, leading to more predictable behavior.
