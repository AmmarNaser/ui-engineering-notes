### State Management - Managing Component State in React

State management is a crucial aspect of building interactive applications in React, as it determines how data flows and is updated in a component tree. Understanding how to effectively manage state is essential for creating responsive and maintainable user interfaces.

### When to Use It
- **Local State Management**: Use state management when dealing with data that only needs to be local to a single component, such as form inputs or toggling visibility.
- **Global State Management**: Opt for state management solutions like Context API or Redux when dealing with shared state across multiple components, such as user authentication status or application settings.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>{count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <button onClick={() => setCount(count - 1)}>Decrement</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **useState Hook**: The `useState` hook is a built-in React hook that enables state management within functional components, making it easy to manage local component state.
- **State Updates**: State is updated asynchronously, meaning that if you need to derive new state from the previous state, it's best to use the functional updater form of `setState`.

By effectively managing state, React applications can behave predictably and provide a smooth user experience.
