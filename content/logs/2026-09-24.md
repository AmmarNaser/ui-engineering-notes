### Custom Hooks - A Way to Reuse Logic

Custom hooks in React enable developers to encapsulate and reuse stateful logic across components, enhancing code maintainability and readability. They allow you to share functionality without changing your component hierarchy.

### When to Use It
- **Shared Logic**: When multiple components require the same stateful logic, custom hooks help avoid duplication.
- **Complex State Management**: When managing complex component states and effects, custom hooks can simplify the orchestration of such logic.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Component using Custom Hook
function DataFetchingComponent() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return <div>{JSON.stringify(data)}</div>;
}
```

### Explanation
- **Encapsulation**: Custom hooks encapsulate logic that can be reused and shared between components, reducing redundancy.
- **Separation of Concerns**: By moving logic out of components and into hooks, you maintain the single-responsibility principle, making components cleaner and easier to manage.

Custom hooks are a powerful tool in React that can drastically improve code organization and reusability throughout your application.
