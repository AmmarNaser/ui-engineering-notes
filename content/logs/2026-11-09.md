### Hooks - Managing State in Functional Components

React Hooks are a powerful feature that allows you to use state and other React features in functional components. They enable a more functional programming style, making it easier to manage component state and side effects without needing to convert your components to class components.

### When to Use It
- **State Management**: Use Hooks when you need to manage local component state without converting to a class component.
- **Side Effects**: Utilize Hooks for handling side effects like data fetching, subscriptions, or manual DOM manipulations within functional components.

### Example
```jsx
import React, { useState, useEffect } from 'react';

const ExampleComponent = () => {
    const [count, setCount] = useState(0);
    const [data, setData] = useState([]);

    useEffect(() => {
        fetch('https://jsonplaceholder.typicode.com/posts')
            .then(response => response.json())
            .then(json => setData(json));
    }, []); // Empty dependency array means this effect runs once on mount

    return (
        <div>
            <h1>Count: {count}</h1>
            <button onClick={() => setCount(count + 1)}>Increment</button>
            <h2>Fetched Data:</h2>
            <ul>
                {data.map(item => (
                    <li key={item.id}>{item.title}</li>
                ))}
            </ul>
        </div>
    );
};

export default ExampleComponent;
```

### Explanation
- **useState Hook**: This Hook allows you to add state variables to your functional components, providing an easy way to manage state.
- **useEffect Hook**: This Hook manages side effects in functional components, replacing lifecycle methods like `componentDidMount` and `componentDidUpdate`, making code cleaner and easier to read.

Using Hooks can significantly simplify component logic and improve code reusability. They encourage a more declarative approach to handling state and effects in your React applications.
