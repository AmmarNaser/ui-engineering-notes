### Custom Hooks - Reusable Logic in React

In React, custom hooks empower developers to extract and reuse stateful logic across components, improving code organization and reducing duplication.

### When to Use It
- **Stateful Logic Sharing**: When you need to share logic related to state management among several components, such as form handling or API fetching.
- **Complex Logic Abstraction**: When you have complex logic that should be separated from UI components, making code easier to read and maintain.

### Example
```javascript
// useFetch.js - Custom Hook for Data Fetching
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;

// ExampleComponent.jsx - Usage of Custom Hook
import React from 'react';
import useFetch from './useFetch';

const ExampleComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default ExampleComponent;
```

### Explanation
- **State Management**: The custom hook manages its own state (data, loading, error), allowing components that use it to remain focused on presentation.
- **Reusability**: The logic for fetching data is encapsulated within `useFetch`, making it reusable across different components without rewriting code.

By leveraging custom hooks, developers can create clean, maintainable, and reusable code structures in React applications. Implementing this concept can significantly enhance your coding efficiency and component organization.
