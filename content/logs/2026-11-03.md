### Custom Hooks - Reusable Logic in React

Custom Hooks are a way to encapsulate shared logic between React components, enabling code reuse and better organization. They allow developers to extract component logic into reusable functions, which can help align the component's state and side effects without altering the component structure.

### When to Use It
- **Shared State Logic**: When multiple components share similar stateful logic, creating a Custom Hook allows for clean and maintainable code. 
- **Complex Effects**: If you're dealing with complex side effects that are used in multiple places, a Custom Hook can simplify and standardize how the effect is implemented.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetchData(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        };
        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Usage in a component
const DataDisplay = ({ url }) => {
    const { data, loading, error } = useFetchData(url);

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error.message}</p>;

    return (
        <div>
            <h1>Data:</h1>
            <pre>{JSON.stringify(data, null, 2)}</pre>
        </div>
    );
};
```

### Explanation
- **Reusable Logic**: The `useFetchData` hook can be reused in different components, maintaining a clean structure and reducing code duplication.
- **Encapsulated Side Effects**: It handles the fetching logic, state management, and error handling all within the hook, leading to clearer component code.

By leveraging Custom Hooks, React developers can enhance the reusability and readability of their components, ultimately leading to more efficient and maintainable codebases.
