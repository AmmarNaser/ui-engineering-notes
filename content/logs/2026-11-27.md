### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to encapsulate and reuse stateful logic across components. By creating hooks that manage state or handle side effects, you can keep your component code clean and more manageable.

### When to Use It
- **Stateful Logic Reuse**: When you have logic that needs to be shared between multiple components, such as form handling or API fetching.
- **Encapsulating Side Effects**: When managing side effects in a component, a custom hook can help organize those effects, avoiding clutter in your component's code.

### Example
```javascript
// useFetch.js
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;

// ExampleComponent.js
import React from 'react';
import useFetch from './useFetch';

const ExampleComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default ExampleComponent;
```

### Explanation
- **Flexibility**: Custom hooks allow you to create flexible hooks that can be easily reused across various components without duplicating code.
- **Separation of Concerns**: By extracting logic into custom hooks, you improve the readability of your components and adhere to the separation of concerns principle.

Custom hooks are a key tool in a React developer's toolkit, enabling cleaner and more maintainable code.
