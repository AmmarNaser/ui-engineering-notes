### Custom Hooks - Building Reusable Logic in React

Custom hooks are a powerful feature in React that allow you to encapsulate and reuse stateful logic between components. They enable enhanced code organization and promote the DRY (Don't Repeat Yourself) principle by allowing you to extract component logic into reusable functions.

### When to Use It
- **State Management**: When multiple components need to share or use the same state logic without duplicating code.
- **Effect Logic**: When you have side effects (e.g., fetching data, subscriptions) that need to be reused across different components.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom hook for fetching data
function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Example component using the custom hook
function App() {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error.message}</p>;

    return (
        <div>
            <h1>Data</h1>
            <pre>{JSON.stringify(data, null, 2)}</pre>
        </div>
    );
}
```

### Explanation
- **Reusable Logic**: Custom hooks allow you to abstract complex logic for fetching data or managing state, making your components cleaner and easier to manage.
- **Encapsulation**: They encapsulate state and side effects, which can help maintain a clearer separation of concerns within your application structure.

Custom hooks can significantly enhance the maintainability and reusability of your code, making it a fundamental technique for efficient React development.
