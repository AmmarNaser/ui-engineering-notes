### Custom Hooks - Simplifying State Management in React

Custom hooks are a powerful feature in React that allows developers to extract logic from components into reusable functions. They enable better organization, reduce duplication, and enhance the maintainability of the codebase.

### When to Use It
- **Stateful Logic Reuse**: When you have stateful logic that needs to be used across several components, a custom hook can help centralize this functionality.
- **Complex Component Logic**: If a component has complex logic involving multiple states or effects, creating a custom hook can simplify the component and improve readability.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetch(url) {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      }
    };
    fetchData();
  }, [url]);

  return { data, error };
}

// Component using the custom hook
function DataDisplay({ apiUrl }) {
  const { data, error } = useFetch(apiUrl);

  if (error) return <div>Error: {error.message}</div>;
  if (!data) return <div>Loading...</div>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Encapsulation of Logic**: The custom hook `useFetch` encapsulates the fetching logic, making it reusable across different components with minimal effort.
- **Simplified Components**: The component `DataDisplay` remains focused on rendering logic without getting bogged down by data fetching details.

By using custom hooks, you can create cleaner, more organized, and reusable code in your React applications.
