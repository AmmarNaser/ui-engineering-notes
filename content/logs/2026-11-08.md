### Custom Hooks - Reusable Logic in React

Custom hooks in React are a powerful way to encapsulate and reuse stateful logic across components. They allow developers to create functions that utilize React's built-in hooks, making the codebase cleaner and more maintainable.

### When to Use It
- **Shared Logic**: When you have multiple components that need to share the same stateful logic, creating a custom hook helps to abstract that logic into a single function.
- **Code Organization**: If you find that a component is becoming too complex because of the amount of logic it handles, consider extracting some of that logic into a custom hook.

### Example
```jsx
// useCounter.js
import { useState } from 'react';

export const useCounter = (initialValue = 0) => {
  const [count, setCount] = useState(initialValue);
  
  const increment = () => setCount(prevCount => prevCount + 1);
  const decrement = () => setCount(prevCount => prevCount - 1);
  const reset = () => setCount(initialValue);
  
  return { count, increment, decrement, reset };
};

// CounterComponent.jsx
import React from 'react';
import { useCounter } from './useCounter';

const CounterComponent = () => {
  const { count, increment, decrement, reset } = useCounter(0);
  
  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={increment}>Increment</button>
      <button onClick={decrement}>Decrement</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
};

export default CounterComponent;
```

### Explanation
- **Reusability**: Custom hooks enable you to reuse stateful logic, making your components cleaner and reducing duplication.
- **Encapsulation**: They allow you to encapsulate related logic and state, which can simplify component structure and enhance maintainability.

Custom hooks are a great way to keep your code organized and reduce redundancy, ultimately making your React applications more efficient and easier to work with.
