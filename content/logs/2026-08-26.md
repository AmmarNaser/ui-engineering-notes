### Custom Hooks - Reusable Logic in React

Custom Hooks allow you to extract component logic into reusable functions, enhancing code organization and maintaining a clean component structure. They are a powerful feature for sharing code between components without changing the component hierarchy.

### When to Use It
- **Shared Logic**: When you have logic that needs to be reused across multiple components, such as data fetching, form handling, or local storage interactions.
- **Component Cleanliness**: Whenever a component becomes too complex or lengthy, consider using a custom hook to separate concerns and improve readability.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch(url)
      .then(response => {
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        return response.json();
      })
      .then(setData)
      .catch(setError);
  }, [url]);

  return { data, error };
}

// Example Component using the custom hook
function DataFetchingComponent() {
  const { data, error } = useFetch('https://api.example.com/data');

  if (error) return <div>Error: {error.message}</div>;
  if (!data) return <div>Loading...</div>;

  return <div>Data: {JSON.stringify(data)}</div>;
}
```

### Explanation
- **Reusability**: Custom Hooks provide a way to encapsulate logic that can be reused across different components without duplicating code.
- **Separation of Concerns**: They allow you to keep your components focused on UI rendering while moving non-UI logic into hooks, making components cleaner and easier to maintain.

By leveraging Custom Hooks, you can create scalable and maintainable React applications, ensuring that your component logic remains organized and reusable.
