### Custom Hooks - Reusable Functionality in React

Custom hooks are a powerful feature in React that allow developers to encapsulate reusable logic and stateful behavior. By creating custom hooks, you can keep your component code clean and maintainable while promoting reuse across different components.

### When to Use It
- **Shared Logic**: When multiple components need to share the same logic or state management, creating a custom hook allows encapsulation of this behavior without duplicating code.
- **Complex Logic Separation**: If a component has complex logic that could be simplified, you might create a custom hook to streamline the component's functionality.

### Example
```jsx
import { useState, useEffect } from 'react';

function useWindowWidth() {
    const [width, setWidth] = useState(window.innerWidth);

    useEffect(() => {
        const handleResize = () => setWidth(window.innerWidth);
        window.addEventListener('resize', handleResize);
        
        // Cleanup listener on unmount
        return () => window.removeEventListener('resize', handleResize);
    }, []);

    return width;
}

function App() {
    const windowWidth = useWindowWidth();

    return (
        <div>
            <h1>Window Width</h1>
            <p>{`Current window width is: ${windowWidth}px`}</p>
        </div>
    );
}

export default App;
```

### Explanation
- **Modularity**: Custom hooks allow for modularization of code, making it easier to manage and reason about.
- **State Management**: They can encapsulate state management and specific side effects, simplifying component logic and enhancing readability.

By using custom hooks, you can write more efficient and organized React applications, leveraging shared logic across multiple components.
