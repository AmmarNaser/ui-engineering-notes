### React State Management - Understanding useState Hook

In React, managing state effectively is crucial for creating interactive components. The `useState` hook allows functional components to have state variables, enabling dynamic user interfaces.

### When to Use It
- **Local State Management**: Use `useState` when you need to manage state that is specific to a single component and does not need to be shared across components.
- **Form Inputs**: Utilize `useState` for handling form input values within a component, making it easier to control form submissions and updates.

### Example
```jsx
import React, { useState } from 'react';

const App = () => {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <h1>Counter: {count}</h1>
      <button onClick={increment}>Increase</button>
    </div>
  );
};

export default App;
```

### Explanation
- **State Declaration**: `const [count, setCount] = useState(0);` declares a state variable `count` initialized to `0` and a function `setCount` to update its value.
- **Event Handling**: The `increment` function updates the state. When the button is clicked, it triggers this function, demonstrating reactivity in the UI.

Using `useState` effectively can significantly enhance the interactivity of components.
