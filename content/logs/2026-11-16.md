### Custom Hooks - Creating Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to extract component logic into reusable functions. They can simplify the complexity in component state management, data fetching, and other side effects, making your code cleaner and more maintainable.

### When to Use It
- **State Management**: When you have shared logic across multiple components that need to manage state, custom hooks help encapsulate that logic.
- **Data Fetching**: If several components fetch similar data from an API, creating a custom hook for the fetching logic promotes code reuse and reduces duplication.

### Example
```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error.message);
      }
    };

    fetchData();
  }, [url]);

  return { data, error };
};

// Example component using the custom hook
const UserList = () => {
  const { data: users, error } = useFetch('https://jsonplaceholder.typicode.com/users');

  if (error) return <div>Error: {error}</div>;
  if (!users) return <div>Loading...</div>;

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
};
```

### Explanation
- **Reusability**: Custom hooks allow you to encapsulate and reuse logic across multiple components without repeating code.
- **Separation of Concerns**: By moving logic outside of the component, custom hooks promote a clearer separation of state management and rendering logic, making components easier to read and test. 

Custom hooks are a great way to streamline your React applications, allowing for cleaner and more maintainable code structures.
