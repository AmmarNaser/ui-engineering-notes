### Custom Hooks - Simplifying Reusable Logic in React

Custom hooks are a powerful feature in React that allows developers to extract reusable logic from components into standalone functions. By isolating logic, custom hooks promote cleaner code and facilitate code reuse across different components.

### When to Use It
- **Code Reusability**: When you have shared logic that needs to be used in multiple components, implementing a custom hook allows you to manage that logic in one place.
- **Separation of Concerns**: If a component has complex logic that makes it difficult to read or maintain, consider creating a custom hook to encapsulate that logic, keeping your component clean and focused.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook to fetch data
const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

// Usage in a component
const DataDisplay = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return <div>{JSON.stringify(data)}</div>;
};
```

### Explanation
- **Encapsulation of Logic**: Custom hooks allow you to encapsulate data fetching or other logic in a reusable way, making it easy to use across different components.
- **Improved Readability**: By moving complex logic out of components and into hooks, your components become much easier to read and maintain, focusing solely on the UI.

Incorporating custom hooks into your React projects can make your codebase more manageable and promote best practices around code reuse.
