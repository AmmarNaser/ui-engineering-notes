### Component Lifecycle - Understanding React Component Lifecycle Methods

In React, understanding the component lifecycle is crucial for managing component behavior during different phases of its existence. This concept allows developers to hook into specific moments in a component's lifecycle to perform tasks such as data fetching, cleanup, or animation.

### When to Use It
- **Initialization**: Use lifecycle methods like `componentDidMount` to initialize state, fetch data, or set up subscriptions when a component is first added to the DOM.
- **Updates**: Utilize methods like `componentDidUpdate` to respond to changes in props or state, allowing for actions like re-fetching data based on updated inputs.

### Example
```jsx
import React, { Component } from 'react';

class UserProfile extends Component {
  constructor(props) {
    super(props);
    this.state = {
      user: null,
    };
  }

  componentDidMount() {
    // Fetch user data when component mounts
    fetch(`https://api.example.com/users/${this.props.userId}`)
      .then(response => response.json())
      .then(data => this.setState({ user: data }));
  }

  componentDidUpdate(prevProps) {
    // Re-fetch user data if userId prop changes
    if (this.props.userId !== prevProps.userId) {
      fetch(`https://api.example.com/users/${this.props.userId}`)
        .then(response => response.json())
        .then(data => this.setState({ user: data }));
    }
  }

  render() {
    const { user } = this.state;
    return (
      <div>
        {user ? <h1>{user.name}</h1> : <p>Loading...</p>}
      </div>
    );
  }
}

export default UserProfile;
```

### Explanation
- **componentDidMount**: This lifecycle method is called once the component is inserted into the DOM, making it an ideal place for data fetching.
- **componentDidUpdate**: This method is invoked immediately after updating occurs, allowing you to react to prop or state changes and perform necessary updates without unnecessary data fetching. 

Understanding these lifecycle methods enhances your ability to manage components effectively and respond to their state and data needs throughout their lifecycle.
