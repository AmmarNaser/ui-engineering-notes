### React State Management - Understanding useState Hook

State management is a fundamental concept in React that allows developers to create dynamic and interactive applications. The `useState` hook is one of the primary ways to manage state in functional components, enabling straightforward handling of component-level state.

### When to Use It
- **Simple State Management**: Use `useState` when you need to manage simple state values like form inputs, toggles, or counters within a functional component.
- **Local Component State**: It's ideal for situations where the state does not need to be shared with other components, keeping the state local and straightforward.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  const increment = () => setCount(count + 1);
  const decrement = () => setCount(count - 1);

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={increment}>Increment</button>
      <button onClick={decrement}>Decrement</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Declaration**: The `useState` function initializes the state variable (`count`) and a function to update it (`setCount`).
- **State Update**: When the buttons are clicked, the `increment` and `decrement` functions update the state appropriately, causing the component to re-render with the new count.

This pattern is essential for creating interactive applications and understanding how to manage component states effectively.
