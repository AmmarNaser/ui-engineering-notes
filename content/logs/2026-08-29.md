### React Hooks - Managing State with useState

React Hooks are a powerful feature introduced in React 16.8 that allow you to use state and other React features without writing a class. The `useState` hook is one of the most commonly used hooks, making it easier to manage component state in a functional component.

### When to Use It
- **Simple State Management**: Use `useState` when you need to manage a small amount of state within a functional component, such as a toggle or form input.
- **Dynamic User Interfaces**: When you want to create dynamic user interfaces that respond to user input, `useState` is ideal for tracking changes in data.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>You clicked {count} times</p>
            <button onClick={() => setCount(count + 1)}>
                Click me
            </button>
            <button onClick={() => setCount(count - 1)}>
                Decrement
            </button>
        </div>
    );
};

export default Counter;
```

### Explanation
- **State Initialization**: `useState` initializes the state variable (`count`) and provides a function (`setCount`) to update it.
- **Reactivity**: When the state changes via `setCount`, the component re-renders to reflect the updated state, ensuring the UI remains in sync with the data.

By effectively utilizing `useState`, you can simplify state management in your functional components, leading to cleaner and more maintainable code.
