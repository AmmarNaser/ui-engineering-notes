### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to extract component logic into a reusable function. This promotes better code organization and reduces redundancy, making your components cleaner and easier to maintain.

### When to Use It
- **Stateful Logic**: When you have stateful logic that needs to be shared across multiple components, custom hooks allow you to encapsulate that logic and reuse it easily.
- **Side Effects Management**: If you're handling side effects in your components and need to reuse that behavior, custom hooks can simplify the process and keep your components focused on rendering.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom hook to manage an input field
function useInput(initialValue) {
    const [value, setValue] = useState(initialValue);

    const handleChange = (event) => {
        setValue(event.target.value);
    };

    return {
        value,
        onChange: handleChange,
    };
}

// Sample component using the custom hook
function TextInput() {
    const inputProps = useInput('');

    return (
        <input
            type="text"
            {...inputProps}
        />
    );
}
```

### Explanation
- **Reusable Logic**: Custom hooks encapsulate logic that can be reused across different components, minimizing code duplication and increasing maintainability.
- **Simplifying Complexity**: By moving complex logic into custom hooks, your components can remain simpler and more focused on rendering UI, leading to better separation of concerns.

Using custom hooks can significantly enhance the structure of your React applications, making it easier to manage shared functionality.
