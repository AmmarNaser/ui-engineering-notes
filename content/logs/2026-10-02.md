### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to encapsulate reusable logic and share stateful behavior between components. By creating a custom hook, you can keep your components clean and focused while implementing complex logic in a modular way.

### When to Use It
- **State Management**: When you need to manage state that is shared across multiple components and want to avoid prop drilling.
- **Side Effects Handling**: When you need to handle side effects consistently in different components, such as fetching data or subscribing to events.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom hook to fetch data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err);
      }
    };
    fetchData();
  }, [url]);

  return { data, error };
}

// Component using the custom hook
function DataDisplay({ url }) {
  const { data, error } = useFetch(url);

  if (error) return <div>Error: {error.message}</div>;
  if (!data) return <div>Loading...</div>;

  return (
    <ul>
      {data.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}
```

### Explanation
- **Encapsulation of Logic**: Custom hooks allow you to encapsulate logic related to state and lifecycle methods, reducing the need for the same code in multiple components.
- **Improved Code Reusability**: By creating a custom hook like `useFetch`, you can easily reuse it across different components, allowing for cleaner and more maintainable code.

Using custom hooks can significantly enhance the organization and efficiency of your React applications, making complex stateful logic easier to manage and share.
