React Hooks - Efficient State Management with useState

React Hooks allow function components to manage state and side effects more efficiently, making it easier to build complex UIs without the hassle of classes. Among these hooks, `useState` is one of the most commonly used for managing component-level state.

### When to Use It
- **Dynamic Form Inputs**: Use `useState` to manage user input in forms, allowing for real-time updates and validation feedback.
- **Toggle Components**: Manage the open/closed state of components like modals or dropdowns, enabling intuitive interactions based on user actions.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  const increment = () => setCount(count + 1);
  const decrement = () => setCount(count - 1);

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={increment}>Increment</button>
      <button onClick={decrement}>Decrement</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Initialization**: `useState` initializes the state variable (`count`) with a default value (0 in this case), and provides a function (`setCount`) to update it.
- **Reactivity**: The component re-renders automatically whenever the state changes, ensuring the UI is always in sync with the underlying data.

Using `useState` simplifies state management in React, especially for function components, allowing for cleaner and more maintainable code.
