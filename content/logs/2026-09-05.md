### Custom Hooks - Enhancing Component Logic Reusability

Custom Hooks allow developers to extract component logic into reusable functions, making it easier to share common functionality between React components. This can lead to cleaner code, improved readability, and easier maintenance.

### When to Use It
- **Shared Logic Across Components**: When you find yourself duplicating logic between multiple components, consider creating a custom hook to encapsulate that functionality.
- **Complex State Management**: If a component’s state management is getting complex, a custom hook can simplify the state logic and make it more manageable.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for Fetching Data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example Component Using the Custom Hook
function DataFetchingComponent() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Encapsulated Logic**: The `useFetch` custom hook encapsulates the fetching logic, making the data fetching reusable across any component without repeating the same code.
- **Simplified State Handling**: The custom hook manages loading, error, and data states internally, providing a clean interface for any component that uses it. 

Custom Hooks are a powerful feature in React that can greatly increase the modularity and reusability of your code.
