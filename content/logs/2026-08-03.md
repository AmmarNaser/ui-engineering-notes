### useEffect - Managing Side Effects in React

The `useEffect` hook is a built-in React hook that allows you to perform side effects in function components. It is essential for handling things like data fetching, subscriptions, or manually changing the DOM in your React application.

### When to Use It
- **Data Fetching**: Use `useEffect` to fetch data from an API when your component mounts.
- **Event Listeners**: Use it to set up and clean up event listeners on component lifecycle.

### Example
```javascript
import React, { useState, useEffect } from 'react';

const ExampleComponent = () => {
    const [data, setData] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            const response = await fetch('https://api.example.com/data');
            const result = await response.json();
            setData(result);
        };

        fetchData();
    }, []); // Empty dependency array means this runs once after the initial render

    return (
        <div>
            <h1>Data from API:</h1>
            {data ? <pre>{JSON.stringify(data, null, 2)}</pre> : <p>Loading...</p>}
        </div>
    );
};

export default ExampleComponent;
```

### Explanation
- **Data Fetching**: The `useEffect` hook is perfect for fetching data, as it runs after the initial render and can be set to trigger on specific dependencies.
- **Cleanup**: If you need to perform cleanup (like unsubscribing from an event listener), you can return a function from the `useEffect`, which is called when the component unmounts or before the effect runs again.

By understanding and using `useEffect`, you can effectively manage side effects in your React applications, leading to cleaner and more efficient code.
