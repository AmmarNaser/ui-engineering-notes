### Custom Hooks - Reusable Logic in React

Custom Hooks are a powerful feature in React that allow developers to encapsulate logic that can be shared across multiple components. This pattern promotes reusability and keeps the component code clean and focused on rendering.

### When to Use It
- **Shared Logic Across Components**: When you have multiple components that need to share common logic, such as fetching data or managing a stateful value.
- **Encapsulating Complex Logic**: If a component has complex logic that can be isolated, creating a custom hook can help shrink the component’s size and improve readability.

### Example
```javascript
import { useState, useEffect } from 'react';

// A custom hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example component using the custom hook
function DataDisplay() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;
  return <div>Data: {JSON.stringify(data)}</div>;
}
```

### Explanation
- **Reusability**: Custom hooks allow you to extract and reuse component logic without affecting the component tree.
- **Separation of Concerns**: By moving logic out of components, you achieve a clearer separation between logic and UI rendering, making the codebase easier to manage.

Using custom hooks can significantly enhance the structure and maintainability of your React applications.
