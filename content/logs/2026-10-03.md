### Custom Hooks - Reusable Logic in React Components

Custom hooks in React allow you to extract and reuse stateful logic across different components without needing to change their component hierarchy. They enable cleaner and more manageable code by encapsulating functionality in a way that can be shared across your application.

### When to Use It
- **Sharing Logic**: Use custom hooks when you have stateful logic that needs to be shared across multiple components.
- **Simplifying Components**: Apply custom hooks to simplify component implementation by isolating complex logic or effects from the JSX structure.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetchData(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Component using the Custom Hook
function DataDisplay({ url }) {
  const { data, loading, error } = useFetchData(url);

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return <pre>{JSON.stringify(data, null, 2)}</pre>;
}
```

### Explanation
- **Encapsulation**: Custom hooks encapsulate related stateful logic, making it easy to reuse the logic without duplicating code.
- **Cleaner Components**: By using custom hooks, components focus solely on rendering UI, while the logic handling is abstracted away, leading to cleaner and more maintainable code.

By employing custom hooks, developers can ensure their React applications are both efficient and easy to read, facilitating better collaboration and more straightforward updates in the future.
