### React Hooks - Managing State in Functional Components

React Hooks are functions that let developers use state and other React features in functional components. They simplify component behavior, promote reusability, and enhance code readability.

### When to Use It
- **State Management in Functional Components**: Use hooks when you want to manage state in a functional component without converting it to a class component.
- **Lifecycle Methods**: Use hooks like `useEffect` to perform side effects in your component, such as data fetching or subscriptions.

### Example
```javascript
import React, { useState, useEffect } from 'react';

const Counter = () => {
  // Declare a state variable 'count' with a default value of 0
  const [count, setCount] = useState(0);

  // Effect that runs on component mount and updates the document title
  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]); // Dependency array - runs effect when 'count' changes

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>Click me</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State with `useState`**: The `useState` hook allows you to add state variables to functional components, making them more dynamic.
- **Side Effects with `useEffect`**: The `useEffect` hook enables you to handle side effects (like fetching data or changing the document title) in a clean and manageable way.

In summary, React Hooks provide essential functionality for managing state and side effects in functional components, simplifying code and promoting better practices in React development.
