### React Hooks - Managing State with useState

React Hooks are a powerful feature introduced in React 16.8 that allow functional components to manage state and side effects without the need for class components. One of the most commonly used hooks is `useState`, which provides a way to add state management to functional components.

### When to Use It
- **Simple State Management**: Use `useState` when you need to manage simple pieces of state in your functional component, such as form inputs or toggle switches.
- **Component Re-rendering**: Utilize `useState` to trigger component re-renders when the state changes, allowing you to reflect updates in the UI seamlessly.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>You clicked {count} times</p>
            <button onClick={() => setCount(count + 1)}>
                Click me
            </button>
        </div>
    );
};

export default Counter;
```

### Explanation
- **State Initialization**: The `useState` hook initializes a state variable (`count`) with a default value of `0`, and provides a function (`setCount`) to update it.
- **Event Handling**: When the button is clicked, the `setCount` function updates the state, which triggers a re-render and updates the displayed count.

In summary, `useState` is essential for managing local state in functional components, enhancing the component's interactivity without additional complexity from class components.
