### Custom Hooks - Reusable Logic in React

Custom hooks in React allow developers to extract component logic into reusable functions. This helps in maintaining cleaner code and encourages the sharing of logic across components, enhancing consistency throughout an application.

### When to Use It
- **Stateful Logic Reuse**: Whenever you have logic involving state management that you want to share across multiple components.
- **API Calls**: When you need to handle fetching data from an API in several components, creating a custom hook can keep your code DRY (Don't Repeat Yourself).

### Example
```javascript
// useFetch.js - Custom Hook
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    
    fetchData();
  }, [url]);

  return { data, loading, error };
};

// ExampleComponent.js
import React from 'react';
import useFetch from './useFetch';

const ExampleComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default ExampleComponent;
```

### Explanation
- **Key Point**: Custom hooks can manage complex states and side effects, centralizing the logic and making components simpler.
- **Another Point**: They follow the same naming convention (prefix `use`) and rules as standard React hooks, ensuring that they integrate seamlessly with the React ecosystem. 

By utilizing custom hooks, you can create cleaner, more organized, and reusable code across your React applications.
