### Custom Hooks - Reusable Logic in React

Custom hooks in React allow developers to extract component logic into reusable functions. This enables the sharing of stateful logic between components without changing their structure, leading to cleaner and more maintainable code.

### When to Use It
- **Shared State Logic**: When multiple components need to share the same logic for state management (e.g., fetching data).
- **Complex State Management**: When managing complex components that require shared effects or state, using a custom hook can simplify the logic.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
const useFetch = (url) => {
    const [data, setData] = useState(null);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            }
        };

        fetchData();
    }, [url]);

    return { data, error };
};

// Component using the custom hook
const DataDisplay = ({ apiUrl }) => {
    const { data, error } = useFetch(apiUrl);

    if (error) return <div>Error: {error.message}</div>;
    if (!data) return <div>Loading...</div>;

    return <pre>{JSON.stringify(data, null, 2)}</pre>;
};
```

### Explanation
- **Custom Hook Usage**: The `useFetch` hook encapsulates the logic for fetching data, allowing any component to access it easily.
- **Encapsulation of Logic**: By using a custom hook, the fetching mechanism is separated from the component's UI logic, enhancing code maintainability and clarity.

By leveraging custom hooks, React developers can create modular and reusable components, improving the overall architecture of their applications.
