### Custom Hooks - Enhanced Component Logic

Custom hooks in React allow developers to encapsulate and reuse stateful logic across multiple components. They are a powerful feature that promotes code reusability and helps keep components clean and focused on rendering UI.

### When to Use It
- **Shared Logic**: When multiple components need to share common stateful logic, such as fetching data or handling form input.
- **Complex State Management**: When a component's logic becomes complex, moving the logic into a custom hook can simplify component code and enhance readability.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (error) {
                setError(error);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Usage in a component
function DataDisplay() {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error.message}</p>;

    return <div>{JSON.stringify(data)}</div>;
}
```

### Explanation
- **Encapsulation of Logic**: Custom hooks encapsulate reusable logic allowing you to manage state and side effects in a centralized location.
- **Improved Readability**: By abstracting logic away from component markup, custom hooks enhance the readability and maintainability of your components.

Custom hooks are an invaluable tool for creating clean, reusable logic in your React applications, streamlining your codebase while improving your development workflow.
