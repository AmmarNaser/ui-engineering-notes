### Custom Hooks - Reusable Logic for React Components

Custom Hooks are a powerful feature in React that allows developers to extract component logic into reusable functions. This promotes cleaner code and enhances the maintainability of React applications by enabling shared stateful behavior.

### When to Use It
- **Code Reusability**: When you have common logic, such as data fetching or form handling, used across multiple components.
- **Separation of Concerns**: When you want to keep your component code clean by separating complex logic or side effects into distinct functions.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Using the custom Hook in a component
function DataFetchingComponent({ url }) {
  const { data, loading, error } = useFetch(url);

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <ul>
      {data.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}
```

### Explanation
- **Key Point**: Custom Hooks allow developers to encapsulate reusable logic, making components easier to read and maintain.
- **Another Point**: They follow the same rules as React components, ensuring state and lifecycle management benefits across multiple uses.

Custom Hooks are a valuable tool for enhancing your React applications by promoting logic reuse and cleanliness.
