### Custom Hooks - Simplifying State Logic Reusability

Custom hooks in React allow developers to encapsulate and reuse stateful logic across different components. By creating these reusable functions, we can simplify our code, making it cleaner and more manageable, while also promoting consistency throughout our application.

### When to Use It
- **State Logic Repetition**: When multiple components share similar state logic, creating a custom hook allows you to extract that logic and reuse it, maintaining a single source of truth.
- **Complex Logic**: When dealing with complex state management that requires encapsulating multiple state variables or effects, a custom hook can help in organizing this logic better.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetchData(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Using the Custom Hook in a Component
function DataFetchingComponent() {
  const { data, loading, error } = useFetchData('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return <div>{JSON.stringify(data)}</div>;
}
```

### Explanation
- **Code Reusability**: Custom hooks enable the reuse of stateful logic across multiple components without duplicating code.
- **Separation of Concerns**: They promote a cleaner separation of concerns, making components easier to read and maintain by isolating complex logic in dedicated functions.

Creating custom hooks not only streamlines the development process but also allows for better organization of code, leading to a more efficient and scalable React application.
