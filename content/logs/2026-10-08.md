### Custom Hooks - Reusable Logic in React

Custom hooks in React allow developers to encapsulate logic and share it across multiple components. By leveraging custom hooks, you can enhance code reusability and maintainability, making your components cleaner and more manageable.

### When to Use It
- **Shared Logic**: When you need to share stateful logic between multiple components, such as fetching data or managing forms.
- **Complex State Management**: When you have complex state logic that can be abstracted out into a function for easier testing and maintenance.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch(url)
      .then(response => {
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        return response.json();
      })
      .then(data => {
        setData(data);
        setLoading(false);
      })
      .catch(error => {
        setError(error);
        setLoading(false);
      });
  }, [url]);

  return { data, loading, error };
}
```

### Explanation
- **Reusability**: Custom hooks allow you to encapsulate functionality that can be reused across different components, thereby minimizing code duplication.
- **Separation of Concerns**: They help in separating business logic from UI logic, leading to cleaner and more focused components.

By using custom hooks, you promote better organization within your React applications, making it easier to manage and scale over time.
