### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow you to encapsulate and reuse stateful logic across your components. By creating custom hooks, you can abstract away complex logic and keep your component code clean and maintainable.

### When to Use It
- **Shared Logic**: When multiple components need to share the same stateful logic, a custom hook can help eliminate code duplication.
- **Complex State Management**: For handling complex logic related to state management or side effects that need to be reused, a custom hook can simplify your component structure.

### Example
```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

// Usage in a component
const MyComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return <div>{JSON.stringify(data)}</div>;
};
```

### Explanation
- **Reusability**: Custom hooks allow you to write logic once and reuse it across multiple components, making your code DRY (Don't Repeat Yourself).
- **Separation of Concerns**: By moving complex logic out of your components, custom hooks help keep your component code cleaner and focused solely on UI rendering.

Custom hooks can greatly enhance the organization and reusability of your React applications, making it easier to manage stateful logic effectively.
