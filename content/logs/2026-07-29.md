### Hooks - Managing State in Functional Components

Hooks are a powerful feature in React that allow developers to use state and other React features in functional components, which were previously only available in class components. Using hooks makes it easier to manage state and side effects without the need for class-based structures, leading to more concise and readable code.

### When to Use It
- **State Management**: Use hooks when you need to manage component state in a functional component, such as when handling user input or toggling a UI element.
- **Side Effects**: Apply hooks when you need to perform side effects like fetching data or subscribing to events after the component renders.

### Example
```jsx
import React, { useState, useEffect } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **useState Hook**: This hook allows you to add state to your functional component; in the example, it initializes the `count` state to 0 and provides a `setCount` function to update it.
- **useEffect Hook**: This hook allows you to perform side effects such as updating the document title when the `count` state changes. The second argument `[count]` ensures the effect runs only when `count` is updated.

Hooks provide a more intuitive approach to managing component state and side effects, making your React applications more maintainable and readable.
