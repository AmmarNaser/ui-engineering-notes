### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allows developers to extract and reuse stateful logic across components. They promote code reuse and help keep components clean and focused on their UI responsibilities.

### When to Use It
- **State Management**: When you need to manage state and behavior that is shared between multiple components.
- **Data Fetching**: When fetching data from an API in multiple components, ensuring consistent management of loading states and error handling.

### Example
```javascript
import { useState, useEffect } from 'react';

// A custom hook for fetching data
function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (error) {
                setError(error);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Usage in a component
function MyComponent() {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error.message}</div>;
    return <pre>{JSON.stringify(data, null, 2)}</pre>;
}
```

### Explanation
- **Reusability**: Custom hooks allow for code that can easily be reused across different components, avoiding duplication.
- **Separation of Concerns**: They help separate business logic from UI concerns, making components more focused and testable. 

By using custom hooks, developers can create cleaner, more maintainable code while promoting the DRY (Don't Repeat Yourself) principle in their React applications.
