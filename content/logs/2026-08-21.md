### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to extract component logic into reusable functions. By creating custom hooks, you can share stateful logic across multiple components, improving code organization and reusability.

### When to Use It
- **State Management**: Use a custom hook to manage form state and validation logic that can be shared across various forms in your application.
- **Data Fetching**: Implement a custom hook for fetching data from an API, allowing you to encapsulate the fetching and error handling logic in one location, making it reusable across different components.

### Example
```javascript
// useFetch.js
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

// ExampleComponent.js
import React from 'react';
import useFetch from './useFetch';

const ExampleComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>Data from API</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default ExampleComponent;
```

### Explanation
- **Reusable Logic**: Custom hooks allow you to encapsulate and reuse logic across multiple components without duplicating the code.
- **Side Effects Handling**: Custom hooks can effectively manage side effects, like data fetching, while abstracting the complexity away from components.

By leveraging custom hooks, React developers can enhance code maintainability and efficiency, allowing for cleaner and more modular applications.
