React Hooks - Managing State with useState

React Hooks introduced a new way to use state and lifecycle features in functional components, simplifying component management and promoting clearer code organization. The `useState` hook is a fundamental aspect of this evolution, allowing developers to declare state variables directly in functional components.

### When to Use It
- **Basic State Management**: Use `useState` when you need to maintain and manage a simple state value, like form inputs or toggle switches.
- **Dynamic Rendering Requirements**: Implement `useState` to manage values that, when changed, should trigger re-renders of the component to reflect updated UI.

### Example
```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Declaration**: The `useState` hook is invoked to create a piece of state (`count`) and a function to update it (`setCount`).
- **Reactivity**: When the button is clicked, `setCount` updates the state, which re-renders the component to reflect the current count.

In summary, `useState` is essential for managing local state in functional components, enabling straightforward and efficient user interactions within React applications.
