### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow you to encapsulate and reuse stateful logic across multiple components. By creating custom hooks, you can abstract complex logic into a standalone function, improving code organization and reusability.

### When to Use It
- **Code Reusability**: When you find yourself repeating the same stateful logic in multiple components, a custom hook can help you avoid code duplication and enhance maintainability.
- **Complex State Management**: If a component's logic is getting too complex, especially involving multiple state variables or side effects, a custom hook can simplify that logic and separate concerns.

### Example
```javascript
// useCounter.js - A simple custom hook for managing a counter
import { useState } from 'react';

const useCounter = (initialCount = 0) => {
  const [count, setCount] = useState(initialCount);

  const increment = () => setCount(prevCount => prevCount + 1);
  const decrement = () => setCount(prevCount => prevCount - 1);
  const reset = () => setCount(initialCount);

  return { count, increment, decrement, reset };
};

// App.js - Using the custom hook in a component
import React from 'react';
import useCounter from './useCounter';

const App = () => {
  const { count, increment, decrement, reset } = useCounter(5);

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={increment}>Increment</button>
      <button onClick={decrement}>Decrement</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
};

export default App;
```

### Explanation
- **State Management**: The custom hook `useCounter` manages the counter's internal state, providing a clear API for other components.
- **Reusability**: It can be used in multiple components without needing to duplicate the counter logic, promoting a DRY (Don't Repeat Yourself) codebase.

Custom hooks are invaluable for creating modular and maintainable React applications by encapsulating logic that can be shared across different components.
