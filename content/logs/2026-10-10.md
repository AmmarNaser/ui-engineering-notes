### Custom Hooks - Creating Reusable Logic in React

Custom hooks are a powerful feature in React that allow you to encapsulate and reuse stateful logic across components. They help in keeping your component code clean and focused while promoting code reusability.

### When to Use It
- **Shared Logic**: When you have stateful logic that needs to be reused across multiple components, such as form handling or API fetching.
- **Separation of Concerns**: To organize complex components by separating business logic from UI rendering, making your components easier to maintain and test.

### Example
```javascript
// useFetch.js - A custom hook for fetching data
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

// Example of using the custom hook in a component
const DataDisplay = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;
  
  return <div>{JSON.stringify(data)}</div>;
};
```

### Explanation
- **Reusability**: Custom hooks enable the extraction of logic that can be reused across different components, which reduces redundancy.
- **Isolation**: By using custom hooks, you can keep your component UI code separate from the logic, which helps in creating a more manageable and testable codebase.

Custom hooks can significantly enhance the structure and maintainability of your React applications, leading to cleaner and more efficient code.
