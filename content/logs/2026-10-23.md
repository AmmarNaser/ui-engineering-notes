### React State Management - Understanding useState Hook

In React, managing state effectively is crucial for building dynamic user interfaces. The `useState` hook provides a simple and efficient way to add state to functional components.

### What is it?
The `useState` hook is a fundamental feature of React that allows you to add state to functional components. Instead of relying on class components, which use `this.state` and `this.setState`, functional components can utilize `useState` to manage state without the overhead of classes. This matters because it leads to cleaner, more readable code while leveraging React's reactivity.

### When to Use It
- **Simple State Management**: Use `useState` when you need to manage local state in a functional component, such as form inputs or toggles.
- **Component-Specific Values**: Utilize `useState` to handle state that is only relevant to a specific component rather than using a global state solution.

### Example
```jsx
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={increment}>Click me</button>
    </div>
  );
}

export default Counter;
```

### Explanation
- **State Initialization**: `useState(0)` initializes the `count` state variable with a default value of `0`.
- **State Update Function**: `setCount` is a function that updates the state value; when called, it triggers a re-render of the component with the new state.

Using the `useState` hook allows for a more modular approach to state management in React, enabling developers to write less code and focus on the component's logic and presentation.
