### Custom Hooks - Simplifying State Logic

Custom hooks are a powerful feature in React that allows you to extract component logic into reusable functions. They enable you to share reusable logic across components without changing the component hierarchy, making your code cleaner and more maintainable.

### When to Use It
- **Complex State Logic**: When you have complex state logic that is used in multiple components, creating a custom hook can help centralize that logic for better management.
- **Shared Functionality**: When different components require similar functionality (e.g., fetching data), a custom hook can encapsulate that functionality so it can be shared across your application.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example component using the custom hook
function MyComponent() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Encapsulation of Logic**: Custom hooks allow any complex logic to be encapsulated in one place, facilitating easier testing and maintenance.
- **Reusable Across Components**: Once created, a custom hook can be reused in any component, promoting DRY (Don't Repeat Yourself) principles in your codebase.

Custom hooks can dramatically improve the structure and clarity of your React applications, promoting code reuse and separation of concerns.
