### Custom Hooks - Creating Reusable Logic in React

Custom hooks in React allow developers to extract component logic into reusable functions. They help promote code reuse and make your components cleaner and more manageable.

### When to Use It
- **State Management**: When you have similar stateful logic that needs to be shared across multiple components, such as form handling or API calls.
- **Side Effects**: When you need to handle side effects in a consistent manner across different components, such as data fetching or subscriptions.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (err) {
        setError(err.message);
      }
    };

    fetchData();
  }, [url]);

  return { data, error };
}

// Usage in a component
function App() {
  const { data, error } = useFetch('https://api.example.com/data');

  if (error) return <div>Error: {error}</div>;
  if (!data) return <div>Loading...</div>;

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Reusability**: Custom hooks encapsulate logic, making it easier to share between components without needing to repeat code.
- **Simplicity**: They help keep components clean and focused on rendering UI, separating concerns like data fetching or state management into separate hooks.
