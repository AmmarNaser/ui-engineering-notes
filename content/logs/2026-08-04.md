### Custom Hooks - Reusable Logic in React

Custom hooks allow developers to extract component logic into reusable functions, promoting code organization and reducing duplication. By encapsulating stateful behavior and side effects, custom hooks make it easier to share functionality across multiple components while adhering to React's functional component paradigm.

### When to Use It
- **Stateful Logic Sharing**: When multiple components need to share the same stateful logic, creating a custom hook can simplify your code and reduce redundancy.
- **Complex Side Effects**: If a component has complex side effects that can be abstracted away for cleaner component code, a custom hook allows you to centralize that logic in one place.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const json = await response.json();
        setData(json);
      } catch (err) {
        setError(err);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example component using the custom hook
function App() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **State Management**: The custom hook `useFetch` manages loading states, fetched data, and errors, which simplifies the component's state management.
- **Reusable Logic**: The `useFetch` hook can be reused in any component simply by providing a URL, making it easy to leverage the same functionality across different parts of the application.

Custom hooks are a powerful tool in React that help keep components clean and focused on rendering, while handling complex and repetitive logic in a more maintainable way.
