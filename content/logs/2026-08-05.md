### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allows developers to extract component logic into reusable functions. This promotes cleaner code and enhances maintainability by avoiding duplication.

### When to Use It
- **State Management**: When multiple components need to share the same state logic without prop drilling.
- **Side Effects**: When you have repetitive side effects, such as fetching data, that need to be encapsulated and reused across components.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const data = await response.json();
        setData(data);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example of using custom hook in a component
function App() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Reusability**: Custom hooks allow you to encapsulate logic in a function which can be reused across different components.
- **Cleaner Components**: By separating logic into hooks, your component code becomes easier to read and manage, focusing solely on rendering.

Custom hooks can significantly simplify state management and side effects in React applications, making your codebase more organized and easier to maintain.
