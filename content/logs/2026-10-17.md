### Custom Hooks - Creating Reusable Logic in React

Custom hooks are a powerful feature in React that allows developers to encapsulate and reuse logic across components. By extracting functionality into a custom hook, you can improve code organization and maintainability, while also promoting the DRY (Don't Repeat Yourself) principle.

### When to Use It
- **State Management**: When you need to share stateful logic between multiple components without lifting state up unnecessarily.
- **Side Effects**: When you want to isolate side effects (like data fetching or subscriptions) in a reusable function that can be hooked into various components.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

export default useFetch;
```

### Explanation
- **Data Fetching**: The custom hook `useFetch` manages fetching data from a given URL, handling loading states and errors.
- **Reusability**: This hook can be used in multiple components, allowing them to manage data fetching with consistent behavior and without duplicating code.

Custom hooks provide a versatile way to enhance your React applications by promoting code reuse and simplifying component logic.
