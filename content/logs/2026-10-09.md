### useEffect - Managing Side Effects in Functional Components

The `useEffect` hook is a fundamental feature in React that allows developers to handle side effects in functional components. This powerful tool integrates lifecycle management directly within the functional component structure, enabling better control over when and how side effects occur.

### When to Use It
- **Fetching Data**: Use `useEffect` to fetch data when the component mounts, ensuring that the data is available for rendering.
- **Event Listeners**: Apply `useEffect` to set up and tear down event listeners, helping to manage resources and avoid memory leaks.

### Example
```javascript
import React, { useState, useEffect } from 'react';

const DataFetcher = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch('https://jsonplaceholder.typicode.com/posts');
      const result = await response.json();
      setData(result);
    };

    fetchData();
  }, []); // Empty dependency array means this effect runs once on mount

  return (
    <div>
      <h1>Fetched Data</h1>
      {data ? (
        <ul>
          {data.map(item => (
            <li key={item.id}>{item.title}</li>
          ))}
        </ul>
      ) : (
        <p>Loading...</p>
      )}
    </div>
  );
};

export default DataFetcher;
```

### Explanation
- **Dependency Array**: The second argument to `useEffect` is an array that specifies when the effect should re-run, helping control the effect's lifecycle.
- **Cleanup Function**: `useEffect` can return a cleanup function to execute on component unmount, making it suitable for resource management, like removing event listeners.

The `useEffect` hook is essential for handling side effects in functional components, promoting more readable and maintainable code in React applications.
