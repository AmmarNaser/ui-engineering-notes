### Custom Hooks - Simplifying State Logic Reuse

Custom hooks in React provide a way to encapsulate shared logic and state management in a clean and reusable manner. They allow developers to extract component logic into a separate function that can be utilized across various components, promoting code reusability and maintainability.

### When to Use It
- **State Management Across Components**: Use custom hooks when you have stateful logic that needs to be shared among multiple components, such as API calls or form handling.
- **Simplifying Component Logic**: Implement custom hooks to reduce the complexity of components by extracting intricate state management or side effects, making your components easier to understand and maintain.

### Example
```jsx
import { useState, useEffect } from 'react';

// Custom Hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Using the custom hook in a component
function DataDisplay({ url }) {
  const { data, loading, error } = useFetch(url);

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <div>
      <h1>Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Reusable Logic**: Custom hooks allow you to encapsulate and reuse logic related to state management or side effects (like fetching data), which can drastically simplify your component code.
- **Isolation of Concerns**: By using custom hooks, you can isolate the data-fetching logic, making it easier to test and maintain separately from the UI logic of your components.

Custom hooks are an invaluable tool in React, enabling developers to create cleaner and more modular codebases by promoting the reuse of complex logic.
