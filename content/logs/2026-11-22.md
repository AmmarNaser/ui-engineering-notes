### Custom Hooks - Create Reusable Logic in React

Custom hooks in React allow developers to extract component logic into reusable functions. This facilitates cleaner, more maintainable code and promotes the DRY (Don't Repeat Yourself) principle.

### When to Use It
- **Shared Logic**: When you have logic that is needed in multiple components, such as fetching data or handling form state.
- **Complex State Handling**: When managing complex state-related operations that can be encapsulated for reuse across components.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (error) {
                setError(error);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Usage in a component
function DataDisplay() {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error.message}</div>;

    return <div>Data: {JSON.stringify(data)}</div>;
}
```

### Explanation
- **Encapsulation**: Custom hooks encapsulate logic and state, making components easier to read and manage.
- **Reusability**: They promote reusability across components, reducing code duplication and enhancing maintainability.

Leveraging custom hooks can significantly streamline your React application development, making it more modular and effective.
