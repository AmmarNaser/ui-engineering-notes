### useEffect - Handling Side Effects in Functional Components

The `useEffect` hook is a fundamental part of React that allows developers to manage side effects in functional components. It plays a crucial role in handling operations like data fetching, subscriptions, or directly manipulating the DOM, ensuring that those effects don't interfere with the component's lifecycle.

### When to Use It
- **Data Fetching**: When you need to retrieve data from an API after the component mounts.
- **Event Listeners**: When you want to set up or clean up event listeners that rely on component lifecycle events.

### Example
```jsx
import React, { useEffect, useState } from 'react';

const DataFetcher = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch('https://api.example.com/data');
      const result = await response.json();
      setData(result);
    };
    
    fetchData();

    return () => {
      // cleanup if necessary
    };
  }, []); // Empty dependency array means this runs once after the initial render

  return (
    <div>
      <h1>Fetched Data</h1>
      {data ? <pre>{JSON.stringify(data, null, 2)}</pre> : <p>Loading...</p>}
    </div>
  );
};

export default DataFetcher;
```

### Explanation
- **Lifecycle Management**: `useEffect` is called after the render, allowing for side effects to be managed appropriately.
- **Dependency Array**: By passing a dependency array (here, empty), you control when the effect runs, specifying if it should run on component mount, update, or unmount.

Using `useEffect` ensures that side effects are handled efficiently, promoting clean and maintainable code in React applications.
