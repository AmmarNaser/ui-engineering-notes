### React Hooks - Managing State with useState

React Hooks are a powerful feature introduced in React 16.8 that allow functional components to manage state and side effects without the need for class components. This enhancement simplifies the development of React applications and promotes cleaner, more functional code.

### When to Use It
- **Managing Local State**: Use `useState` when you need to keep track of local state within a functional component, such as toggling a dropdown menu or maintaining input field values.
- **Dynamic Render Control**: Use `useState` for controlling the rendering of components based on user interactions, like updating the UI when a button is clicked.

### Example
```javascript
import React, { useState } from 'react';

const Counter = () => {
    const [count, setCount] = useState(0);
    
    const increment = () => {
        setCount(count + 1);
    };

    return (
        <div>
            <h1>Count: {count}</h1>
            <button onClick={increment}>Increment</button>
        </div>
    );
};

export default Counter;
```

### Explanation
- **State Declaration**: `useState(0)` initializes the state variable `count` to `0`. The first element of the array is the current state, and the second is a function to update it.
- **State Update**: Calling `setCount` updates the state and triggers a re-render of the component, ensuring the displayed count is always up to date.

Using `useState` can significantly enhance the experience of building UI components in React by making them more responsive and easier to manage.
