### Custom Hooks - Creating Reusable Logic in React

Custom hooks allow developers to encapsulate and reuse stateful logic across multiple components in a React application. They pave the way for cleaner and more maintainable code by abstracting away common functionalities.

### When to Use It
- **State Management**: When you have complex component state logic that you want to share between components, custom hooks can help isolate this logic and keep your components clean.
- **Side Effects**: If multiple components need to perform similar side effects, such as fetching data or subscribing to events, a custom hook can simplify and centralize this functionality.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for fetching data
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Example Component using the custom hook
function DataFetchingComponent() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {data.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}
```

### Explanation
- **Reusability**: Custom hooks enable you to extract and reuse stateful logic, making it easier to maintain and update.
- **Cleaner Components**: By abstracting logic into hooks, your component code becomes less cluttered and more focused on rendering.

Custom hooks are a powerful feature in React that can significantly enhance the organization and reusability of your code.
