### Custom Hooks - Enhancing Reusability in React

Custom hooks are a powerful feature in React that allow developers to extract and reuse stateful logic across components without compromising the component structure. They help to keep code clean, organized, and DRY (Don't Repeat Yourself) by encapsulating functionality that can be shared among multiple components.

### When to Use It
- **Stateful Logic Reusability**: When you have stateful logic that needs to be used in multiple components, such as form handling, API calls, or any other shared behavior.
- **Cleaner Components**: When you want to simplify your components by moving complex logic outside, making them easier to read and maintain.

### Example
```javascript
import { useState, useEffect } from 'react';

function useFetch(url) {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
}

// Usage in a component
function App() {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error.message}</div>;
    
    return (
        <div>
            {data && data.map(item => (
                <div key={item.id}>{item.name}</div>
            ))}
        </div>
    );
}
```

### Explanation
- **Modular Logic**: By using custom hooks, you can write modular and reusable logic that can be easily shared across different components.
- **Encapsulation**: Custom hooks keep related logic together. This encapsulation of functionality reduces complexity and enhances maintainability in larger applications.

Custom hooks are a fantastic way to keep your React application organized and efficient. By adopting them, you can significantly improve the reusability of your code.
