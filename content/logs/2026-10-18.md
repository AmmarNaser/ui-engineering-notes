### Custom Hooks - Streamlining State Logic in React
Custom hooks are a powerful feature in React that allow developers to encapsulate stateful logic and reusable functionality. By creating custom hooks, you can keep your component code clean and organized while improving code reuse across your application.

### When to Use It
- **Shared State Logic**: When multiple components need to share the same stateful logic or side effects, creating a custom hook is an effective way to centralize that logic.
- **Complex State Management**: If a component becomes too complicated with state management and effects, extracting this logic into a custom hook can simplify the component's structure and improve readability.

### Example
```jsx
import { useState, useEffect } from 'react';

// Custom Hook
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Component using the custom hook
function DataFetchingComponent({ url }) {
  const { data, loading, error } = useFetch(url);

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error}</div>;
  
  return (
    <div>
      <h1>Fetched Data:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
```

### Explanation
- **Reusability**: Custom hooks encapsulate logic that can be reused across multiple components, reducing duplication and making the codebase easier to maintain.
- **Separation of Concerns**: By isolating state management and effects in hooks, components become more focused on rendering UI, leading to better separation of concerns and improved readability.

In summary, custom hooks are an excellent way to manage shared state logic in React applications, promoting cleaner code and increased reusability.
