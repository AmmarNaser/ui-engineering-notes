### Custom Hooks - Simplifying State Logic Management

Custom hooks in React are a powerful way to encapsulate stateful logic and share it across components without altering the component hierarchy. They enable better code organization, improve reusability, and enhance readability by separating complex logic from UI components.

### When to Use It
- **Stateful Logic Reuse**: When you have stateful logic that needs to be reused across multiple components, creating a custom hook can help streamline that code.
- **Complex Logic Simplification**: If a component contains complex logic that makes it hard to maintain, extracting it into a custom hook can simplify the component’s structure.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for managing form input
function useFormInput(initialValue) {
    const [value, setValue] = useState(initialValue);

    const handleChange = (event) => {
        setValue(event.target.value);
    };

    return { value, onChange: handleChange };
}

// Example component utilizing the custom hook
function FormComponent() {
    const name = useFormInput('');

    const handleSubmit = (event) => {
        event.preventDefault();
        alert(`Submitted name: ${name.value}`);
    };

    return (
        <form onSubmit={handleSubmit}>
            <input type="text" placeholder="Your Name" {...name} />
            <button type="submit">Submit</button>
        </form>
    );
}
```

### Explanation
- **Encapsulation**: The `useFormInput` hook encapsulates the logic of managing form input, making the `FormComponent` cleaner and easier to read.
- **Reusability**: The custom hook can be reused across different components for various input fields, ensuring consistency in how form data is managed.

Custom hooks are an effective tool for enhancing the maintainability and readability of your React applications. By modularizing your logic, you can focus on building better components.
