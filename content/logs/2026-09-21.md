### Custom Hooks - Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to extract and encapsulate reusable logic across components. By creating custom hooks, you can keep your components cleaner and more focused on rendering UI, leading to improved maintainability and cohesion in your codebase.

### When to Use It
- **Sharing Logic Across Components**: Use custom hooks when you need to share stateful logic across multiple components without duplicating code.
- **Encapsulating Complex Logic**: Apply custom hooks when your component logic becomes too complex, allowing you to keep components focused and easier to reason about.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook for fetching data
function useFetchData(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) throw new Error('Network response was not ok');
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, [url]);

  return { data, loading, error };
}

// Component using the custom hook
function DataFetchingComponent({ url }) {
  const { data, loading, error } = useFetchData(url);

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return <div>Data: {JSON.stringify(data)}</div>;
}
```

### Explanation
- **Reusable Logic**: The custom hook `useFetchData` can be reused in any component that requires data fetching, minimizing repetitive code.
- **Separation of Concerns**: By using a hook, you keep data-fetching logic separate from your UI rendering code, making the components easier to understand and maintain.

Custom hooks are an excellent way to enhance the reusability of code while keeping component logic clean and efficient.
