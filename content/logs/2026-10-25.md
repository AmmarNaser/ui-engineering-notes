### Controlled Components - Managing Form Elements in React

Controlled components in React are form elements whose value is controlled by the component's state. This pattern allows for better control over form data and makes it easier to validate and manipulate user input.

### When to Use It
- **Complex Forms**: When building forms that require validation, conditional rendering, or dynamic data updates.
- **Single Source of Truth**: When you want to ensure that the form state is centralized and reflects the latest value directly from your React component’s state.

### Example
```jsx
import React, { useState } from 'react';

const ControlledForm = () => {
  const [inputValue, setInputValue] = useState('');

  const handleChange = (event) => {
    setInputValue(event.target.value);
  };

  const handleSubmit = (event) => {
    event.preventDefault();
    alert(`A name was submitted: ${inputValue}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Name:
        <input type="text" value={inputValue} onChange={handleChange} />
      </label>
      <button type="submit">Submit</button>
    </form>
  );
};

export default ControlledForm;
```

### Explanation
- **State Management**: The input value is stored in a state variable (`inputValue`), ensuring that the React component controls and reflects the value of the input field.
- **Event Handling**: The `handleChange` function updates the state every time the user types, demonstrating immediate feedback and controlled behavior.

By using controlled components, you can maintain a consistent and predictable form state, enhancing user experience and making it easier to implement additional features like validation or submission logic.
