### React Hooks - Managing State with useState

React Hooks are a powerful feature that allows functional components to manage state and lifecycle methods without converting them into class components. The `useState` hook is particularly important as it enables developers to add state management capabilities simply and elegantly.

### When to Use It
- **Single Component State**: Use `useState` when you need to manage state that pertains to a single component, such as form inputs or toggling UI elements.
- **Local Component Logic**: It is also suitable for scenarios where local state is required, as opposed to global state managed by libraries like Redux.

### Example
```javascript
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount(prevCount => prevCount + 1);
  };

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={increment}>Click me</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Initialization**: The `useState` hook initializes `count` with a value of `0`. The `setCount` function is used to update this value.
- **Functional Updates**: By passing a function to `setCount`, we can ensure the state updates are based on the previous state, which helps prevent potential bugs when multiple updates are queued.

In summary, `useState` streamlines state management in functional components, making it easier to create interactive and dynamic user interfaces in React applications.
