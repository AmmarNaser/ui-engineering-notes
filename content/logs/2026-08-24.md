### Custom Hooks - Encapsulating Reusable Logic in React

Custom hooks are a powerful feature in React that allow developers to extract and share common functionality across components. By creating a custom hook, you can encapsulate stateful logic and side effects, making your code more organized and easier to maintain.

### When to Use It
- **Shared Logic**: When you find yourself duplicating code across multiple components that require similar functionality, custom hooks can help you consolidate that logic into a single reusable function.
- **Complex State Management**: For components with complex state transitions or side effects, custom hooks provide a way to manage that complexity outside the component, improving readability and separation of concerns.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch(url)
      .then(response => {
        if (!response.ok) throw new Error('Network response was not ok');
        return response.json();
      })
      .then(data => {
        setData(data);
        setLoading(false);
      })
      .catch(error => {
        setError(error);
        setLoading(false);
      });
  }, [url]);

  return { data, loading, error };
}

// Component using the custom hook
function DataFetchingComponent() {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;
  return <div>Data: {JSON.stringify(data)}</div>;
}
```

### Explanation
- **Reusability**: Custom hooks allow for the reuse of code across different components, reducing duplication and effort for common tasks like data fetching.
- **Encapsulation**: They help keep the component code clean by encapsulating complex logic and side effects, making the component easier to read and test.

Using custom hooks can significantly enhance your React applications by promoting better code organization and reusability.
