### Context API - Managing Global State in React

The Context API is a powerful feature in React that enables developers to manage global state across their applications without the need for prop drilling. This can greatly simplify state management, especially in larger applications.

### When to Use It
- **Global State Management**: When you need to share data across multiple components at different nesting levels without having to pass props down through every intermediary component.
- **Theming**: When you want to provide theme settings (like light and dark modes) across your app, allowing any component to access the current theme without complicated prop chains.

### Example
```jsx
import React, { createContext, useContext, useState } from 'react';

// Create a Context
const ThemeContext = createContext();

// Create a Provider component
const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(prevTheme => (prevTheme === 'light' ? 'dark' : 'light'));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

// Custom hook to use the ThemeContext
const useTheme = () => {
  return useContext(ThemeContext);
};

// Example component using the context
const ThemedButton = () => {
  const { theme, toggleTheme } = useTheme();
  
  return (
    <button onClick={toggleTheme} style={{ background: theme === 'light' ? '#fff' : '#333', color: theme === 'light' ? '#000' : '#fff' }}>
      Switch to {theme === 'light' ? 'Dark' : 'Light'} Mode
    </button>
  );
};

// App component
const App = () => (
  <ThemeProvider>
    <ThemedButton />
  </ThemeProvider>
);

export default App;
```

### Explanation
- **Context Creation**: The `createContext` method is used to create a context, which is a container for the state that needs to be shared.
- **Provider Usage**: The `ThemeProvider` wraps the application and provides state and functions to consuming components through the context.

With the Context API, managing global state becomes straightforward, enhancing the scalability and maintainability of React applications.
