### useState - Managing State in Functional Components

The `useState` hook is a fundamental part of React that allows developers to manage state in functional components. Understanding how to effectively use `useState` is crucial for creating interactive and dynamic user interfaces.

### When to Use It
- **Initial Component Render**: Use `useState` to set up local state for a component and initialize it with a default value during the initial render.
- **Event Handling**: Utilize `useState` to manage changes in state triggered by user interactions, such as input field updates or button clicks.

### Example
```javascript
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0); // Initialize state

  const handleIncrement = () => {
    setCount(prevCount => prevCount + 1); // Update state
  };

  const handleDecrement = () => {
    setCount(prevCount => prevCount - 1); // Update state
  };

  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={handleIncrement}>Increment</button>
      <button onClick={handleDecrement}>Decrement</button>
    </div>
  );
};

export default Counter;
```

### Explanation
- **State Initialization**: The `useState` hook is called with an initial value (in this case, `0`), which sets the initial state of `count`.
- **State Updater Function**: The `setCount` function allows updating the state based on the previous state, ensuring the state updates are based on the most recent value.

By mastering `useState`, developers can create more interactive and efficient React applications.
