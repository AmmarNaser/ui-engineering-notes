### Custom Hooks - Creating Reusable Logic in React

Custom hooks are a powerful feature in React that allow you to encapsulate stateful logic in a reusable function. This concept is essential for separating concerns in your components, promoting cleaner code, and enabling easier testing and maintainability.

### When to Use It
- **State Management**: When you have logic that manages a particular piece of state, such as form handling or fetching data, it can be abstracted into a custom hook.
- **Logic Reusability**: When you find yourself duplicating logic across multiple components, it's a good time to create a custom hook to encapsulate that functionality.

### Example
```javascript
import { useState, useEffect } from 'react';

const useFetch = (url) => {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error('Network response was not ok');
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
};

// Usage in a component
const App = () => {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <div>Loading...</div>;
    if (error) return <div>Error: {error.message}</div>;

    return (
        <div>
            {data.map(item => (
                <div key={item.id}>{item.name}</div>
            ))}
        </div>
    );
};

export default App;
```

### Explanation
- **Encapsulation**: Custom hooks allow you to encapsulate stateful logic, making it easier to manage and reason about.
- **Clean Components**: By moving logic into custom hooks, your component remains focused on rendering UI, improving readability and maintainability.

Custom hooks are an invaluable tool in a React developer's toolkit, facilitating the reuse of complex logic while keeping components clean and concise.
