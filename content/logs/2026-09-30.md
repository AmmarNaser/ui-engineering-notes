React.memo - Performance Optimization for Functional Components

React.memo is a higher-order component that allows you to memoize the result of a functional component, preventing unnecessary re-renders when props have not changed. This technique helps improve performance, especially in applications where components receive the same props frequently.

### When to Use It
- **Static Data**: Use React.memo when you have a functional component that renders the same output for the same set of props, minimizing re-renders on state changes in parent components.
- **Complex Components**: Employ React.memo for complex components that heavily rely on props and require substantial processing; this can significantly reduce rendering times.

### Example
```javascript
import React from 'react';

const HeavyComponent = React.memo(({ data }) => {
  console.log('Rendering HeavyComponent');
  return <div>{data}</div>;
});

const ParentComponent = () => {
  const [count, setCount] = React.useState(0);
  const data = "Constant Data";

  return (
    <div>
      <HeavyComponent data={data} />
      <button onClick={() => setCount(count + 1)}>Increment Count</button>
      <p>Count: {count}</p>
    </div>
  );
};

export default ParentComponent;
```

### Explanation
- **Performance Improvement**: By wrapping the functional component in React.memo, it avoids re-rendering unless the props change, which can enhance performance in larger applications.
- **Shallow Comparison**: React.memo performs a shallow comparison of props; for deeper checks, you can provide a custom equality function as a second argument.

Using React.memo can help optimize your React application by reducing unnecessary renders, resulting in a smoother user experience.
