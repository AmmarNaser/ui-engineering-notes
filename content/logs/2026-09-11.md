### Custom Hooks - Simplifying State Logic

Custom Hooks in React allow developers to extract component logic into reusable functions, promoting code reuse and separation of concerns. This is particularly useful for managing complex stateful logic that can be shared across multiple components.

### When to Use It
- **Stateful Logic Reuse**: When you have stateful logic that you want to share between several components without rewriting the same code.
- **Separation of Concerns**: When you want to isolate component logic for better maintainability and readability.

### Example
```javascript
import { useState, useEffect } from 'react';

// Custom Hook
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);
    
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  return width;
}

// Component using the Custom Hook
function WindowWidthDisplay() {
  const width = useWindowWidth();

  return <div>Window width: {width}px</div>;
}
```

### Explanation
- **Reusability**: Custom Hooks allow you to encapsulate logic and make it easily reusable across different components.
- **Encapsulation of Side Effects**: By using hooks like `useEffect` within your custom hook, you can manage side effects associated with the state changes cleanly and efficiently.

In conclusion, utilizing Custom Hooks is a powerful way to enhance your React applications by keeping your components clean and facilitating the reuse of shared logic.
