### Custom Hooks - Simplifying Code Reusability

Custom hooks in React allow developers to extract component logic into reusable functions. This concept is crucial as it promotes code reusability and separation of concerns, making the codebase cleaner and more maintainable.

### When to Use It
- **State Management**: Use a custom hook to encapsulate complex state logic that you want to share across multiple components.
- **Data Fetching**: Create a custom hook for fetching data from APIs, making it easy to handle loading states and error management in different components.

### Example
```javascript
// useFetch.js
import { useState, useEffect } from 'react';

const useFetch = (url) => {
    const [data, setData] = useState(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                const response = await fetch(url);
                if (!response.ok) throw new Error('Network response was not ok');
                const result = await response.json();
                setData(result);
            } catch (error) {
                setError(error);
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
};

// ExampleComponent.js
import React from 'react';
import useFetch from './useFetch';

const ExampleComponent = () => {
    const { data, loading, error } = useFetch('https://api.example.com/data');

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error.message}</p>;

    return (
        <ul>
            {data.map(item => (
                <li key={item.id}>{item.name}</li>
            ))}
        </ul>
    );
};
```

### Explanation
- **Code Reusability**: Custom hooks allow you to reuse logic across different components without duplicating code.
- **Cleaner Components**: By offloading complex operations into a custom hook, component files stay focused and easier to read, improving overall maintainability.

Custom hooks are a powerful feature in React, enabling developers to write modular and DRY (Don't Repeat Yourself) code for enhanced efficiency and clarity.
